## 1. 坐标系与缩放

**🔴 头号坑：屏幕坐标换算漏了一层缩放。**
页面结构是 `.page scale(--stage-scale)` 里面套 `.alg-rows scale(--fit)`，
`getBoundingClientRect()` 报的屏幕像素经过了**两层**缩放。只除 `--fit` 的症状：
动画跑到别的位置演完再"跳"回来，偏移量正比于窗口缩放比例；
`--fit` 常年是 1、审计又总在 scale=1 下做，于是潜伏了很多轮。
**修法**：不读 CSS 变量，用同一元素自己标定 `k = 屏幕宽 ÷ offsetWidth`——中间再插几层 transform 都不用改。
**检验法**：把窗口拖成非 1280×720 比例再看中间帧。

其他同族：
- 幽灵层坐标在变形前取、变形后用 → 位置差 8px 落在行外。教训：**量完立刻用，跨布局失效**。
- 思维导图叶子的起飞点用 offsetLeft/offsetTop（布局坐标）算，**别碰 getBoundingClientRect**——布局坐标天然免疫缩放。

## 2. 「把行内文字拆成块」家族

同一个病根踩了三次，写成表：

| 现场 | 写法 | 后果 |
|---|---|---|
| .derive-why | display:flex | 每个 em/b 变独立排版块，整句话被打散 |
| .q-aside b | display:block | 正文加粗全部独占一行 |
| .wr > b | display:block | 卡片从 120px 涨到 268px |

**规律**：容器里既有标题元素又有连贯正文时，给容器加 flex、或给 b/em 加 block，正文必被拆行。
**做法**：标题用 `> b:first-of-type`（角标在前时 :first-child 匹配不到）；
要垂直居中就套一层单一子元素；**永远不让 flex 直接面对一串文本节点**。

## 3. 动画时序

- 延迟启动的 `element.animate()` **必须 `fill:"backwards"`**——否则延迟期间元素显示 CSS 静态终态，
  每个新元素都"出现两次"（一轮返工的唯一病根，症状却像三个不同 bug）。
- 后台标签页 WAAPI 冻结 → 落幕只能靠 setTimeout + 卫兵函数，不靠 animation.finished。
- settle() 要能强制 finish 正在跑的第二幕，否则快速连点会叠帧。
- **先补历史行、再变形本体**，反过来 = 旧式子复活。

## 4. 构建管线

- `String.replace` 的替换串里 `$&` `` $` `` `$'` 是特殊记号，压缩过的 JS 满是 `$`——
  内联 katex 就是这样被插坏的。**一律用函数替换 `html.replace(mark, () => body)`**。
- 闸门的 fetch 检测别把 katex 内部 `parser.fetch()` 误伤：用 `(?<![.\w$])fetch\s*\(` 只认裸调用。
- 逐页重复的图走 CSS background 只嵌一次——`<img>` 会每页复制一份 base64（36 页曾多出 3MB）。

## 5. HTML/CSS 静默失效

- `<li data-danger>` 写成 `<lidata-danger>`（少个空格）→ 浏览器不报错，那步**静默消失**。
  批量生成后 `grep -E '<li[a-z-]+='` 扫一遍。
- `.solve{display:flex}` 特异度压过 `[hidden]` → 隐藏失效。显式写 `.solve[hidden]{display:none}`。
- 隐藏元素 scrollTop 写不进去 → 滚轮初值 0:00。露面时再回填。
- 通配 `svg{width:100%}` 会连 KaTeX 的根号 SVG 一起放大到消失——选择器必须限定直接子级。
- IntersectionObserver 在未激活页永不触发 → reveal/completion-check 切页时强制显形兜底。
- 绝对定位水印会盖住内容 → z-index:-1 + 父级 isolation:isolate。
- 只设 disabled 逻辑、忘接 click 的按钮看不出坏——**验按钮必须真点一下看状态变没变**。
- 初始化函数的早退条件要带 booted 标志——首帧早退会让 HTML 里的占位文案（"1 / 5"）永远留在页上。
- 锚点替换脚本：多行注释做锚点容易对不上 → **锚点选独一无二的代码行**，替换后必须验证插入真的发生了。

## 6. KaTeX 尺寸

- 行内 `\dfrac` 把行高撑到 280px → 行内一律 `\tfrac`。
- `\colorbox` 底色画到行盒外，被 overflow-y:hidden 上下削条 → 容器补 padding:3px 0。
- 图内标注禁 √ ∕ 字符拼数学（闸门 G10），画出来或走 KaTeX。

## 7. 审计工具自己的坑

- 浏览器面板隐藏时：getBoundingClientRect 全 0、rAF 不跑、动画值冻结——**先置前再量**。
- 无差别 `document.getAnimations()` seek 会倒带页面切换动画，制造假故障帧——按动画 id 过滤。
- 截图被压缩到 800px 看不清细节 → 把待审 SVG 抽出来放大到单独审计页逐张看。
- 子任务的自检不算数——**逐页目验必须亲自做**（工作纪律）。

## 8. 版面预算

- 推导器高度是**先算出来的**：8 步 ≈ 394px 舞台 + 98px 框架，一页正文只有 636px——
  装不下就拆页，绝不压 --fit（交付时每个推导器 --fit 必须 1.0000）。
- 卡片高度别靠 min-height + flex 撑（见第 2 类），用 padding。
- 滑条预设值走精确通道，步长吸附会毁掉 26/3 这类撞墙点。
- CSS grid 行高不写死，内容一高整行跟着长 → 读数卡被切。

## 9. 只测收起态，漏了展开态

习题页的 `.q` 是**固定 496px 的框**，题干 + 步骤列表 + 按钮条塞不下就往下顶，把整页撑破。
但**收起状态下解法面板是 hidden 的，量不出来**——自检脚本只跑收起态，三页溢出全漏了。

**自检脚本必须先把每一页的解法展开、走到最后一步，再量**：

```js
document.querySelectorAll('.q').forEach(function(q){
  var pg = q.closest('.page'), b = q.querySelector('.sol-btn');
  if (b) b.click();
  var nx = q.querySelector('.sol-nav.next');
  for (var i = 0; i < 20 && nx && !nx.disabled; i++) nx.click();
  if (pg.scrollHeight > 721) console.log('展开后溢出', pg.id, pg.scrollHeight - 720);
});
```

**结构上已经在骨架里兜住**：`makeQuestion` 展开时量一次真实溢出，
超了就给 `.q` 加 `tight` / `tight2`（题干和步骤逐档收小）——
跟推导器的 `--fit` 同一个思路：**宁可字小一点，也不能把内容顶出页面**。
所有步骤从一开始就占位（只是 `visibility:hidden`），所以展开时量一次就够，不用每步重量。

## 10. `data-hl` 写错了位置不报错，只是不亮

图上高亮的键必须写在 **`<li data-hl="键1 键2">`** 上——`makeQuestion` 只读 `li.dataset.hl`。
写在 `<li>` 里面的 `<span data-hl>` 上，浏览器不报错、页面正常显示，**只是图永远不亮**。
交付前逐题点一遍步进，看图上有没有跟着亮。

## 11. chrome 按钮的对比度要按底色分别定

玻璃按钮是无色的，颜色全靠图标——所以**图标色要看它坐在什么底上**：
- 坐在深绿页眉上的（提示音铃铛）→ 图标必须偏白，深色图标在深绿上等于隐形。
- 坐在米白正文上的（翻页、加号、笔迹）→ 图标用 `--brand-deep`。
- **页码这种纯文字更要小心**：原来是白字，翻到浅色页面上整个消失；套一层玻璃药丸 + 深色字才两种底都读得清。

## 12. 悬浮控件要躲开页面自己的按钮

笔迹条一开始放左下角，正好压住推导器的「上一步 / 下一步」。
**页面左下角是推导器的地盘，右下角是导航的地盘**——新增悬浮控件放在导航条正上方最安全。

## 13. 推导器只演「怎么变过去」，不负责把题答完

例 1(2) 问的是「求 **m 的值及相应的两根**」，推导器一路演到 `2m(m−2)=0` 就收了 ——
**变形演完了，题只答了一半**。同理，证 Δ 恒正的那页配方到 `2(m−1)²+2` 就停，
没有那句「所以恒大于 0，方程总有两个不相等的实数根」。

**规矩**：推导器负责**变形过程**；题目真正问的那个东西（值、根、结论句、取值范围）
必须由推导器下方的**结论条**补齐，而且要**回代检验**（这里两组根都要验 x₁=x₂+2）。

**排版预算**：结论条要占 80~100px，所以推导器的高度要**先扣掉它再算**
（这一页最后是 题干 62 + 推导 360 + 结论 ~95 = 584，正好用满）。

**交付前自查一句话**：把题干念一遍，问「它要的每一样东西，页面上都有吗？」

## 14. 引擎里写死课件专属的 id —— 换一课就静默失效

思维导图引擎里的枝顺序原本是硬编码的 `["def","solve","delta","apply"]`（样例那一课的枝名）。
换到新课用 `s1..s4` 之后：
- 点枝本身还能展开（走的是 click → `setOpen(b.dataset.br)` 这条路，读的是真实 id）；
- 但 **▶ 和「揭晓答案」驱动的 `paint()` 全是空转**——它遍历的是四个不存在的 id。
- 更阴的是 `atEnd()` 仍按写死的长度算，于是 **▶ 被白白吃掉 4 次**，老师连按四下页面纹丝不动。

**规矩：引擎里凡是「有哪些东西、什么顺序」，一律从 DOM 现读，不许写死。**

```js
var ORDER = brs.map(function(b){ return b.dataset.br; });   // ✓
// var ORDER = ["def","solve","delta","apply"];             // ✗ 换课即死
```

**同一处还踩了第二遍**：注册那行也写死了页 id ——
`stepDrivers["page-net"] = makeMindmap($("#mmMain"))`。换课页 id 变成 `page-from` 之后，
驱动注册到了一个不存在的页上，▶ 和揭晓按钮全都找不着它。正确写法是按元素自己所在的页注册：

```js
$$(".mm-wrap").forEach(function(w){
  var pg = w.closest(".page");
  if (pg) stepDrivers[pg.id] = makeMindmap(w);     // 有几张导图就注册几张
});
```

**自检**：新课件做完，站在思维导图页连按 ▶，看枝是不是一根一根开出来。
不开 = 引擎里还有写死的东西。用这一句扫全场：
`document.querySelectorAll('.mm-wrap').forEach(w=>{var p=w.closest('.page');
console.log(p.id, !!window.__debugDrivers[p.id])})` —— 每一张都必须是 true。

## 15. 答案不能提前剧透

结论区（`.reveal-after`）默认 `opacity:0`，推导器走到最后一步时才由
`paint()` 给所在页打上 `.derive-done` 让它现身。**推导没演完就把答案摆在下面，中间那八步就白演了。**

总结页同理：空骨架里**要放真内容**（`<span class="lf-txt">` 包住，先盖住），
配一枚「揭晓答案」按钮一键展开 + 亮字。**全是空框子很怪**，学生不知道该说几条；
盖住但有格子，学生才知道"这里应该有三点"。

## 16. 页面最底一条会被右下角导航压住

翻页 ◀ ▶ 和加号是 `position:fixed` 贴在视口右下角的，会盖住页面底部内容的右端。
贴着页面底边、又横贯整页的条，加 `.clear-chrome`（`padding-right:196px`）给它让位。

## 17. 逐行改代码时，删错一行会静默毁掉标签平衡

给思维导图叶子加 `<span class="lf-txt">` 时，我用「改第 i+1 行、插入新行、删第 i+3 行」的逐行手术，
**`del ls[i+3]` 正好删掉了 `o.append('</div>')`** —— 导图的收尾标签没了。
浏览器不报错，只是**后面本该并列的提示条被吞进了导图内部**，跑到左上角压住第一根枝。

**规矩**：
- 逐行改代码属于高危操作，改完**必须打印改动前后各两行**核对，不能只看新插入的那行；
- 生成 HTML 的函数改完，跑一次**标签配平检查**：从容器起点扫 `<div|</div>`，
  深度归零的位置后面紧跟的应该是什么，心里要有数。

```python
i, depth = start, 0
for m in re.finditer(r'<div\b|</div>', s[start:]):
    depth += 1 if m.group().startswith('<div') else -1
    if depth == 0: print("闭合后紧跟：", s[start+m.end():][:60]); break
```

## 18. `.q` 的高度在骨架里写死 496px

题目区是固定高度的（保证翻页时版面不跳）。所以**给一道题的页面再加别的条（结论、SOP）时，
内容删得再多，`.q` 也不会自己缩** —— 必须显式给一个矮版：`.q.short{height:451px}`。
算法：`.q 高 = 584 − 标题栏 45 − 间距 − 你要加的那条的高度`。

## 19. 图上高亮：`data-hl` 只认 `<li>`，写进 span 就静默失效

引擎读的是 `cur.dataset.hl`（`cur` 是当前那个 `<li>`）。把 `data-hl` 写在 `<li>` 里面的
`<span>` 上，**不报错、不高亮**，翻完整题都看不出少了东西 —— 一整页的黄框就是这么丢的。
同一份课件里另外两页用的是正确写法，所以更难发现。

**做法**：生成器给步骤加一个前缀约定，别让人手写属性。本 skill 的 `q()` 用
`"@键1 键2@步骤正文"`（`!` 前缀仍表示易错步，两者可叠加）。

**交付前必跑这一句**（把每页每一步点亮了什么全打出来，肉眼对一遍）：

```js
document.querySelectorAll('.q').forEach(q=>{
  const pg=q.closest('.page'); q.querySelector('.sol-btn').click();
  const nx=q.querySelector('.sol-nav.next'), seq=[];
  for(let i=0;;i++){ const on=[...q.querySelectorAll('.hl.on')].map(h=>h.dataset.k);
    seq.push((i+1)+':'+(on.join('+')||'—')); if(nx.disabled)break; nx.click(); }
  console.log(pg.id, seq.join('  '));
});
```
**每一张带图的题，都必须有若干步是亮的**；整列全是 `—` 就是写错位置了。

## 20. 用词要跟学段对齐

初中没有「取交集」这个说法（那是高中集合语言）。范围合并一律写
**「取公共部分」**：几条画到同一数轴上，都满足的那一段。
同类：初三上还没学二次函数图象，别提「抛物线」「顶点」；没学根式化简，别写「最简二次根式」。
**写任何一个术语前，先问它在本册书里出现过没有。**

## 21. 课件必须自带全屏钮（浏览器的壳会压扁 16:9）

课件是 1280×720 的固定舞台等比缩放的，**比例永远不会错，但会被压小**：
标签栏 + 地址栏 + 书签栏一起吃掉几十到一百多像素高度，投影出来就明显小一圈。
所以右上角常驻一枚玻璃全屏钮（`F` 键也绑了），进全屏后 ResizeObserver 自己重算
`--stage-scale`，不用额外处理。

**两个坑**：
1. `requestFullscreen()` **必须由用户手势触发**，而且返回的是 Promise ——
   同步 `try/catch` 抓不到它的拒绝，要 `.catch()`。
2. **嵌在别的页面里的预览环境会直接拒绝**（`TypeError: Permissions check failed`）。
   所以按钮要有**失败兜底**：闪红 + 把 title 换成「请按 F11（Mac 上 ⌃⌘F）」。
   按了没反应又不吭声，老师只会以为课件坏了。

**验收注意**：**这个功能在内嵌预览面板里测不出真实效果**（面板本身就屏蔽全屏）。
能验的是「按钮在、handler 接上了、兜底会触发」；真正的全屏切换要在真实浏览器里点一次。

## 22. 摸底子任务的额度会到点
批量摸底用几十个子任务，跑到第 22 个撞上账号额度，10 份草案 + 综合全失败。教训：批量任务先跑小批（≤8 个），留 journal 可 resume；主循环自己能干的（汇总、写提案）别等子任务。

## 23. JS 字符串里不许写 `<x-tex>`
build.mjs 对整份文件做 KaTeX 预渲染，JS 字符串里的 `<x-tex>h</x-tex>` 会被换成带双引号的 `<span class="katex">…`，整段脚本语法炸掉（报「Unexpected identifier 'katex'」，全页无 JS）。
运行时拼字符串一律用 `KX("h")`；`<x-tex>` 只出现在 pages.html 里。

## 24. 课件专属 class 撞了共用部件的名
课件专属 CSS 里自定义了 `.pb-fx{opacity:0}` 给图上步进元素用，恰好撞上实验台读数框的 class，整台实验台的解析式空白。
规矩：**课件专属 class 一律带课时前缀**（如 `.l02-fx`），`pb-` 前缀只属于共用部件；共用部件内部 class 也尽量取长名。

## 25. 施工员子任务半途撞额度，主循环必须能接手
几个施工员各写完 6 文件，随后额度到点全部报错，批处理返回全空。
接手办法：`ls build/*/`+`audit.py` 逐份摸底 → 主循环自己修溢出、跑自检、逐页目验。所以施工员的每一步产物都要落盘（不落盘就白干）。

## 26. 复用别课模板时封面 hero 没改
施工员照别的课复制封面，hero 还是「二次函数」，本课却是另一课题。**复用模板的每个字段逐字对：封面 hero、副标题、页眉 topic、title.txt、chip 四处必须同一课。**

## 27. 学生课件里不许出现「原件」二字
「原件写错了，我们改成…」是给老师看的批注。学生面前只说「常见错写」「这一步别漏」；原件错误的说明只进 extract/open_issues。

## 28. 「答案小在前」也管整数列表与并列解
k=−5,−3,−2；m=−1 或 3——不只两根 x₁<x₂。推导器最后一行、结论条、旁白三处口径一致。

## 29. 页底技巧条也受 reveal-after 管
技巧卡或小图里只要写了本题的具体答案（m=−4 取 / −2 舍），就必须和结论条一样加 `.reveal-after`，否则第 1 步就剧透。

## 30. KaTeX 行内公式会在 − < 处折行
题干和步骤里的完整公式用 `<span style="white-space:nowrap">` 包住或提前 `<br>`；audit.py 量不出「不溢出但折断」，只能靠目验。

## 31. 方法页的例子拿了练习题的式子冒充例题（用户在验收时抓到）
方法页标着「例 1(4)」，推导的却是练习第 4 题(4) 的式子。标签和式子必须来自同一道题；交付前把每个「例 N(k)」标签和题干条逐个对回原件。
另：页面高度预算里**标题栏也占 60px**，exq(56)+推导器+技巧条(118) 之外只剩 ≈524−… 五步带分数的推导（≈392px）放不下三卡技巧条，改用一行式 `.sop` 技巧条。

## 47. 矢量图上的高亮：终态要把该亮的都写进最后一步
