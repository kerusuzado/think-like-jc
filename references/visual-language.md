# 视觉语言与版式

**拿不准时照 `references/page-types.md` 的写法抄，不要自由发挥。**

## 1. 舞台与缩放（最重要）
- 逻辑画布固定 **1280×720**，整页 `transform:scale(--stage-scale)` 等比缩放（ResizeObserver）。绝不用响应式字号。
- 页眉 84px；正文 `.page-body` 可用 **584px（含标题栏约 60px）**。任何页 `scrollHeight > 721` 都是溢出事故。
- 页面 overflow-y:auto 不用 hidden：宁可滚动也不静默裁内容。
- 屏幕坐标换算：外面永远套着 `--stage-scale`，用同一元素自标定 `k = 屏幕宽 ÷ offsetWidth`（pitfalls §1）。

## 3. 页眉与页脚
从左到右：**徽记**（白圆底，点击自转一圈）→ 机构名（图或字，可无）→ **居中章节进度点**（当前章被亮色胶囊罩住，换章平滑滑过）→ 右侧课时短标题（≤ 22 字，给右上角两枚按钮让位）→ 底边 3px 进度条。
页底两角深色斜切；右侧可有竖排格言淡水印（opacity .07，z-index:-1）。

## 4. 封面
左 680px 深色斜切色带：chip → hero 大字（打字机光标）→ 副标题 → 署名（可无）→ 短横线 → 节点 chips。
右侧：`brand.json` 给了照片就用照片（斜切 + 顶部暗纱）；没给就是**生成式画板**——按课题名算出色相，深底 + 三团光晕 + 48px 细网格 + 等高线，每份课件都不一样但同族。
左上徽记、机构名（图或字）、右上格言（图或字）均按 brand.json 出现或省略。

## 5. Liquid Glass 设计语言
- **次按钮 = 真玻璃**：`rgba(255,255,255,.34)` + `backdrop-filter:blur(18px) saturate(170%)` + 一圈内高光，**不带色相**。
- **主按钮 = 实色填充**：不透明渐变，玻璃感只在边缘高光与柔投影。
- **绝不在按钮正后方垫色辉光**（遮罩感，被打回过）；辉光只垫在 Dock 面板背后。
- 导图叶子、悬浮面板走玻璃；实色卡（章节枝、答案胶囊）走实色。

## 6. chrome 三件套 + 笔迹 + 全屏 + 灯箱（骨架自带，不用写）
- 右上：玻璃**铃铛**（提示音开关，关时一道斜线）、玻璃**全屏钮**（F 键同效；被拒时闪红提示 F11）。图标偏白（坐在深色页眉上）。
- 右下：玻璃 ◀ ▶ + 玻璃页码药丸（深色字）+ 章节 **+** 号（点开沿弧线 Dock 式扇出章节菜单，每项图标 + 名 + 页码；不许做成下拉菜单）。
- 导航条正上方一列：玻璃**点选放大**、**大字 A+**、**放大镜**、**笔**（见 interaction-motion §7c）。其中笔——扇出红/黄/蓝/绿/黑/紫 + 橡皮 + 清空；笔迹按页各存各的，随舞台缩放；开笔时画布吃指针，Esc 退出。
- **局部放大**：给任何图/表/实验台容器加 `data-zoom`（实验台用 `data-zoom="live"` 保持可拖）+ `data-title`，右上角自动出「⊕ 放大」，点开整屏灯箱（深色毛玻璃 + 94vw×93vh 面板 + 标题条 + ✕，Esc 关）。
- 固定控件与页面内容的关系：**左下角是推导器按钮的地盘，右下角是导航的地盘**；贴页底整条内容加 `.clear-chrome`。

## 7. 字体与公式
- 正文公式写 `<x-tex>…</x-tex>`（构建时 KaTeX 预渲染）；运行时拼公式用 `KX("…")`。
- 推导器行内衬线数学字族，变量斜体。
- 行内禁 `\dfrac`（撑到 280px），用 `\tfrac`；`\colorbox` 需要容器 `padding:3px 0`。
- 长公式用 `<span style="white-space:nowrap">` 包住，或提前 `<br>`，别让它在 − < 处折行。
- 图内数学：真根号真分数，画出来或 KaTeX 浮层（`.ovl` 宿主），禁字符拼。

## 8. 体积纪律
- 逐页重复的图（徽记、水印）走 CSS background，一张只嵌一次 base64。
- KaTeX 字体只留 woff2；单文件目标 < 2.5MB；构建脚本扫到任何外链即失败。
