# 品牌卡：换校徽、照片、校名、署名、色板的唯一入口

课件目录里放一份 `brand.json`（模板已带）。**六个字段全部可选**，给了就替换到和默认版式同一位置；不给就走默认。

```json
{
  "org": "某某中学",                       // 机构名。给了就出现在页眉徽记右侧与封面左上（文字）
  "wordmark": "school-name.png",          // 机构名的图（白字透明底 PNG，≈ 232×27）；给了就代替 org 文字
  "emblem": "school-logo.png",            // 徽记（正方形 PNG/SVG，透明底）；不给用默认几何徽记
  "motto": "格言一句 或 motto.png",        // 给文字 → 封面右上一行字 + 每页竖排淡水印；给图 → 同位置用图；不给 → 无
  "cover_photo": "campus.jpg",            // 封面右半照片（建议 ≥ 1600×1400，横向）；不给 → 生成式画板
  "byline": "数学科组　某某",              // 封面署名；不给 → 不显示
  "palette": { "deep":"#173F3A", "brand":"#1F6B5C", "bright":"#2FA37E", "soft":"#e7f0ec", "light":"#C9E3D8", "light2":"#d8e8e0", "band_end":"#10302C" }
}
```
图片文件放 `我的课/assets/`，只写文件名。

## 默认版式（什么都不给时）
- 色板：墨青 #173F3A 主色、#1F6B5C 交互色、#2FA37E 高亮；米白纸面。
- 徽记：白圆底上的几何环 + 琥珀星火（`assets/brand/default-emblem.svg`）。
- 封面右半：生成式画板——色相由课题名决定，深底 + 三团光晕 + 细网格 + 等高线，每份课件不同但同族。
- 无机构名、无格言水印、无署名。

## 换色板的规矩
- 只改 `palette` 七个值；`deep` 是大面积深底，`brand` 是交互色，`bright` 只做光晕点缀，`light` 是深底上的浅字。
- 课件专属 CSS 里不许写新的品牌色字面量，全部引用令牌（`var(--brand)` 等）。
- 改完看三处：页眉对比度、封面 chip 可读、玻璃按钮图标在深底上偏白。

## 给别的学校用
把四张图放进 assets、填好 brand.json，其余一个字不改。做出来的课件与默认版式在同一位置放同一类元素，只是换了脸。
