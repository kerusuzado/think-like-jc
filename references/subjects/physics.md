# 物理（`--pack review --pack physics`）

来源：2026-09「九上 9 月练习讲评 · 物理」验收版（25 页：热学、内能、热机）。通用讲评规矩先读 `../review-lesson.md`。

## 1. 页面安排
- 选择题按得分率排：最低的两道（62%、47%）各一页步进 + 图，其余三张一页速查卡。
- 每道大题 **讲 → 推 → 拖 → 错在哪**：
  - 讲：q 步进 + 右图；遇到计算只写「（下一页推）」；
  - 推：只把计算小问拆成推导页（`exq` + 推导器 300～320px + 结论条）；
  - 拖：实验台按需（熔化吸热、四冲程、冷热水混合）；
  - 错在哪：只给错得最多的大题。

## 2. 画图：真值
- **先写映射函数，再画**：`px = t => X0 + t * ux`、`py = T => Y20 + (20 - T) * uy`；刻度用循环从真值生成，不许手标。
- 能量条：`sc = 画宽 / 最大值`，三条长度 1.38 : 1.0 : 0.276 就真的是这个比例；figcaption「条形长度按真实数值比例画」。
- 分子模型 `phMolecules(g, cx, cy, r, "solid"|"liquid"|"gas")`：固体方阵、液体挨近但乱、气体稀疏；位置只用 `PH.rnd(i, k)`（截图可复现），**禁 Math.random**。
- 内燃机 `phEngine(L, ov, W, H, {s, cx, cy, a:曲轴转角, keys:true})`：真实曲柄连杆运动学（曲柄 r=34s、连杆 100s，顺时针，0° 活塞在最高点），返回 `{stroke, pistonDown, …}`；高亮组 `vl` 气门、`pis` 活塞、`rot` 转向、`rod` 连杆。四冲程判断：两个气门都关 + 活塞下行 + 火花 = 做功冲程。
- 冷却曲线用指数模型：T = Teq + (T0 − Teq)e^{−t/τ}；讲评页和实验台共用同一个函数，实验台只改参数。
- `PH.init(svg)` 后第一行必须 `ov.innerHTML = ""`（不清浮层会一层层叠）；`PH.arrow` 要传颜色。
- 点名（A、B、C）斜体 Times：`PH.T(L.lbl, x, y, "B", {i:true, s:17})`；数值标签 `PH.K(ov, W, H, x, y, "\\text{温度不变：0 ℃}", "jp-amb", "tBC")`。

## 3. 推导器：物理计算三行
公式 → 带单位代入 → 结果；**单位换算那一步黄底**（`role:"hl"`），sub 写「黄底 = 功率单位 W＝J/s，时间要用秒」；label 直接写换算式「10 min = 600 s」。
同一个物理量从头到尾用同一个 id（别把面积 S 的 id 挪去装单位 J）；推导器 token 是纯文本、写不出下标：带下标的量在推导器里写「Q吸」，**同一页的题干、结论条也写「Q吸」**，别一处 KaTeX 下标、一处纯文本（两套写法一眼就不整齐）。
结论条 `.reveal-after` 里用 `.jp-warn` 写错写值、人数、**差几倍**（「差了 60 倍」）。

## 5. 写法
- 标题写物理结论：「第 4 题 · 熔化要吸热，吸热要有温差」「第 14 题 ② · 有用功：时间先换成秒」。
- 从单位读公式：「J/(m²·h) 是『每平方米、每小时多少焦』：乘 S、乘 t，剩下的就是 J。」
- 空白题给得分策略：「本问 142 人空白：写出 W=Fs 就有 1 分。」
- 等号句说本质：「闻到气味＝香味分子自己跑到了鼻子里：扩散。」「打气＝外界对气体做功」。
- 拆开看似相关的量：「用时不同只说明放热快慢不同。」
- 效率：「效率＝有用的 ÷ 总的，结果一定小于 1」。
