# 语文（`--pack review`）

来源：2026-09「九上 9 月练习讲评 · 语文」验收版（27 页）。通用讲评规矩先读 `../review-lesson.md`。

## 1. 页面安排（按试卷顺序：积累运用 → 古诗文 → 信息阅读 → 现代文 → 作文 → 附加题 → 易错八处）
| 情况 | 处理 |
|---|---|
| 选择题得分率高（≥ 82%） | 2～3 题一页速查卡 |
| 选择题要演示（病句改法）或得分率不高 | 单题步进页 |
| 主观题 | 一题一页 q 步进，右边放「语文图」 |
| 小问 < 50% 或丢分集中在一个得分点 | 拆专页（9(2) 拆成 9a 翻译 + 9b「乐之」意动） |
| 老师看原卷判、没有数据（默写、附 1） | 只对答案，明写「阅卷系统没有给出人数，本页只对答案」 |
| 丢分最重的板块 | 板块末尾「错在哪（学生原话，不带姓名）」 |
| 作文 | 两页：档次热力表（幸福写在哪、各档多少人）→ 单句升格 |

## 2. 语文图 = 把原文 / 表格用 HTML 重排，高亮打在文字上（不是原图叠框）
```html
<figure class="q-fig jp-fig jp-text" data-title="第 18(1) 题"><div class="figwrap">
  <div>……寒冷<b class="jp-dot"><span class="th hl" data-k="b1">缠裹</span></b>着他……</div>
  <div class="jp-blocks">
    <div class="jp-blk th hl" data-k="b1"><i>词义<em>1 分</em></i><b>缠裹＝缠绕包裹</b></div>
    <div class="jp-blk th hl" data-k="b2"><i>对象特点<em>1 分</em></i><b>……</b></div>
    <div class="jp-blk th hl" data-k="b3"><i>人物形象<em>1 分</em></i><b>……</b></div></div>
  <div class="jp-indep">三块独立给分：哪一块写对，哪一块就有分</div>
  <div class="jp-stack">
    <div class="jp-smp tr hl" data-k="s1"><div class="jp-sq"><i>学生原话</i>……</div>
      <div class="jp-sm"><span class="jp-mk miss"><b>词义</b>空着</span><span class="jp-mk ok"><b>特点</b>写到了</span><span class="jp-got">得 <b>1</b> / 3 分</span></div></div>
  </div></div><figcaption>把学生原话放进三个得分块，看哪块空着</figcaption></figure>
```
- 两种角色：`.th.hl` 常显、到步变黄（原文句、材料卡、得分块）；`.tr.hl` 到步才出现（答案、错译、结论、原话、出处圆点）。**用反了就是剧透或看不见原文。**
- 右栏加宽：`R.q(..., wide=520)`（带表格的 600）。
- 原文长、字小：`.jp-fig.jp-text.jp-cam-on` 开跟题运镜（点亮哪句推到哪句）。**可点的按钮放在 figwrap 外面**，不然被运镜推出画面。
- figcaption 写删节与来源：「阅读材料较长，只摘答题用到的句段；全文请对照试卷原卷」「示例取自参考答案」「心情曲线按情节走向示意」。

## 3. 各题型讲法
- **默写**：说明条（「错一字、漏一字、添一字，这一句都不给分」）→ `.jp-seq` 逐句揭（挖空处斜纹遮罩）→ 方法小贴士「读批注找诗句」。不写人数。
- **病句**：先读通顺的 → 读意思判断前后关系 → 原关联词表示什么关系、为什么不通（红步，给答案）→ `.jp-fix` 换一换（四组关联词，`data-ok="1"` 标对的，`data-m` 说明「转折：条件艰苦，他却……读通了」）。
- **照示例补写 / 仿写**：先拆示例格式（「做什么＋多少量＋提升什么」）或句式骨架表 → 每空答案 → 丢分人数 + 典型错写（红步）。
- **选择加理由**：抓题干两个关键词（「广州」「岭南」这类地域词）→ 每个关键词扣一条理由。
- **文言翻译**：先圈得分字（`<b class="jp-gold">往</b>` 荧光底）→ 每个得分字**先揭学生错译（带人数），再揭正译** → 连成整句；特殊句式单开一页：错译 → 结构（以 + 之 + 为 + 乐）→ 学过的同类（邑人奇之）→ 口诀。
- **甲乙对读**：观点 → 原文依据；`.jp-chipbar` 点观点亮依据句，错误观点做成 `.bad` 按钮 + `data-note`（「乙文里找不到撑得起『乐观豁达』的句子：121 人这样写」）。
- **诗词鉴赏 / 赏析**：逐字逐层解 → 氛围或态度从哪来 → 得分块 + 原话逐块判 →「答题时可以直接分三句写」。
- **找不正确**：先盯「仅」「只」「一定」这类把话说死的词；A～D 逐项回原文。
- **筛选概括**：每则材料一行 → 结论药丸（一则材料不一定只出一个结论）。
- **标题内涵**：实物 → 指引 → 成长 → 信仰；「答任意三层就满分」；答成「标题作用」的人数（红步）。
- **作文**：定档依据 → 各档人数 → 升一档的办法 → 下一页单句升格（只摘单句，标「改法示范」「一等上原句」）。

## 4. 写法
- 先错后正：「『往』280 人丢分：译成『看见、见到』，把『去』这个动作丢了。」
- 每个概括词都要能在原文里找到撑腰的句子。
- 如实交代评分口径：「只认意动译法：把……当作快乐／以……为乐」「阅卷按参考答案的方向判，这类没给分」。
- 点名答非所问：「那是标题的作用，这道题问的是内涵，这部分不给分。」
- 原话一字不改（错别字也保留），只摘单句，不带姓名。
- 引号用「」，嵌套『』；结论前用 →。
