# 数学（`--pack math`；讲评课再加 `--pack review`）

新授 / 训练 / 复习 / 应用课的数学做法已写在 `../content-standards.md`、`../page-types.md`、`../../assets/packs/math/README.md`，示范课见 `demo/`。

讲评课里数学和物理共用这些要点：
- 几何图用原图叠高亮（`.hl` 框 / `.hl.tri`），坐标图、函数图用 `PB.grid` 重画真值。
- 计算题：讲评页只说思路，推导页演变形；关键一步黄底（`role:"hl"`），结论条回代检验并写错写值与人数。
- 选择题同样分「速查卡」和「单题页」；错项的人数走 `{键.B}` 占位符。
- 示范讲评课 `demo/review/` 就是一节数学（相遇与追及）小测讲评，全部页型可照抄。
