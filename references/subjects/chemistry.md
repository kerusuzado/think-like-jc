来源：2026-09「九上 9 月练习讲评 · 化学」验收版（23 页）。通用讲评规矩先读 `../review-lesson.md`。

## 1. 页面安排
- 选择题 ≥ 85% 的按考点凑成速查卡（第 1、2、3、9 题：化学研究什么 / 化学变化 / 化学性质），< 80% 的一题一页。
- 大题：讲评页（小问多就拆 a / b）→ **误区实验台**（只做错得最多的那个点）→ 必要时专属交互（表达式拼装台）→ 「错在哪」只给丢分最重的 1～2 道大题。

## 2. 图：全部像素坐标 SVG 重画（理化生的装置、曲线可以重画，几何图仍用原图叠高亮）
- 装置一律用 `CH` 零件拼：`CH.glass` 器壁、`CH.tube` 导管（外深内白的空心双描边）、`CH.stopper` 橡胶塞、`CH.lamp` 酒精灯、`CH.jar / jarDown` 集气瓶（可装水）、`CH.flask` 锥形瓶。
- 教材 A～F 六套装置：`chDevices(L, ov, W, H, [{n:"A", x, y, s, k:"A", …}])`；注射器查气密性：`chSyringe(L, ov, W, H, {x, y, s, d:推+/拉-, col, bub})`。
- **刻度、液面、读数用函数从真值算**：量筒 `ml = v => by - 12 - (v - 20) * 3.8`、注射器 `mlY = v => sBot - v / 100 * (sBot - sTop)`；科普图表的数组按原图读数抄。
- 正确项绿框、错误项黄框：`PH.glow(L, key, x, y, w, h, "rgba(34,197,94,.22)")`；勾叉 `PH.mark(g, x, y, ok)`。
- figcaption：「装置重画；注射器刻度按真实体积」「图 2 按原图数据重画」「灰线＝原题所画；绿线＝正确的样子」。
- **化学常规目验**：试管口略向下倾斜、长颈漏斗下端伸入液面（液封）、排水法集气瓶口朝下、多功能瓶排水收气**短进长出**、排空气收密度大的气体长进短出、加热固体用酒精灯外焰。

## 3. 误区实验台（复现本卷错得最多的点）
| 例 | 拖什么 | 回答什么 |
|---|---|---|
| 仰视量取 | 眼睛高度 | 视线对准 42 刻度时，实际液面多高（视线斜率真算）→ 仰视读数偏小、实际偏大 |
| 气密性 | 活塞推 / 拉 + 时间 | 漏气时水柱回落 → 为什么答案必须写「**稳定**」 |
| 多功能瓶 | 通入量 + 短管 / 长管 | 短进长出才收得到 |
统一结构：`.guess`「先猜再拖：」把学生错得最多的问题原样问出来 → 滑条 + 预设 → `.ro-good` 三态（正常绿 / `.jp-bad` 红，写「{键.错} 人填了偏小」/ `.jp-neutral` 灰）。

## 4. 表达式拼装台（`.jx-wrap`）
「反应物 / 条件 / 生成物」三格，条件格在箭头上方。chip：
```html
<button type="button" class="jx-chip" data-row="k" data-kind="c" data-ok="0" data-msg="42 人这样写：没有燃烧，条件是加热">点燃</button>
```
干扰项取学生真实写过的错（人数来自阅卷记录）；三格全对整行 `.done`。底部提示：「条件写在箭头上方；如果用等号，就必须配平。」

## 5. 写法
- 行文化学式用 Unicode 下标：MnO₂、H₂O₂；文字表达式用 KaTeX：`\text{高锰酸钾}\xrightarrow{\text{加热}}\text{锰酸钾}+\text{二氧化锰}+\text{氧气}`，外包 `.jp-nw`。
- 错因点名概念区别：「『生成氧化镁』是结论，现象只能写看到的『白色固体』」「烟是固体小颗粒，雾是小液滴」「148 人写『助燃性』：那是化学性质，题目问物理性质」。
- 给评分口径：「只写『液面上升』的不给分」「多选题漏选不给分」「用等号必须配平」。
- 术语跟现行教材：「烧杯要垫**陶土网**加热」（不是石棉网）。
- 因果链：「氧气比水轻 → 聚在瓶子上部 → 出水口要在下面 → 长管伸到瓶底，出水」。
- 记住这一类：「仰视读数偏小、实际偏大；俯视读数偏大、实际偏小。」
