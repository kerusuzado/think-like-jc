# 成绩分析报告（第七种场景：给老师看的数据报告）

来源：2026-09「数学成绩分析 · 九上 9 月练习」验收版（22 页，633 人 × 25 题）。页面上每个数字都按原始点位逐项重算、口径完全吻合（下表「✔」）。
**读者是科组 / 年级老师，不是学生**：页面含学生姓名，封面必须有保密条「含学生姓名，勿外传」。它和讲评课是两件事——讲评课按题号讲给学生，成绩分析按「年级 → 班 → 人」给老师，结论落到「谁该做什么」。

> **一切数字由装配台 / 脚本从成绩表现算，模型一个数字都不写。** 模型只做：①问清口径 ②确认有哪些表 ③写「共性问题」里「差在哪」一句话（只写老师给了原话的）④核对自检条。

## 1. 要老师给的表（CSV / Excel）

| 表 | 必 / 选 | 列 |
|---|---|---|
| A 成绩表 | 必 | `考号,姓名,班级,1,2,…`；第 2 行 `满分,,,3,3,…`；可选第 3 行 `答案,,,D,C,…`（选择题格子填字母就能出选项分布）。总分自动算 |
| B 题目表 | 必 | `题号,考点,题型` —— 考点 ≤ 12 字 |
| C 班级表 | 必 | `班级,显示名,重点班(是/否)` |
| D 梯度线 | 选，**有就呈现** | `线名,参照人数,参照名次`（按名次折算）或 `线名,分数线`（直接用分数） |
| E 历次名次 | 选 | `考号,七上期中,…,上次`；第 2 行 `参考人数,625,…`；逐人年级名次，缺考留空 |
| F 给分点 | 选 | `题号,步骤,分值,班级,没拿满人数,共丢分`（或逐人长表） |
| G 典型错例 | 选 | `题号,步骤,学生原话,差在哪,截图文件名`（截图先裁掉姓名） |

**开工前只许问、不许猜**：考试名、满分、四率阈值、梯度线口径和线名、「上次」指哪次、重点班、名单能不能进页面、截图是否已去姓名。

## 2. 指标口径（照这个算，别自创）

N 参考人数，F 满分，t 总分。

| 指标 | 口径 |
|---|---|
| 平均分 | Σt/N，1 位小数 ✔ |
| 优秀 / 良好 / 及格率 | t ≥ 80% / 70% / 60% F ✔（阈值可配） |
| 低分率 | **t ≤ 40% F（含等号）** ✔ —— 用 < 会算错 |
| 标准差 | 总体 σ = √(Σ(t−均)²/N)（原 deck 没有，学校要，补上） |
| 最高 / 最低 / 中位数 | 补上（学校要） |
| 四率着色 | 和年级比：高于绿、低于红；**低分率反过来** |
| 名次 | 竞争排名 1,2,2,4… ✔ |
| 题目得分率（难度） | Σ得分 /（人数 × 该题满分）×100，按整题 ✔ |
| 区分度 | 前 27% 与后 27% 的得分率差 /100；< 0.2 标「区分度差」 |
| **梯度线（名次折算）** | Nk = round(参照名次 × N / 参照人数)；分数线 = 分数降序第 Nk 人的分数 ✔ |
| 达线 | t ≥ 分数线（并列会使达线人数 > Nk，正常） ✔ |
| 梯度段 | 一梯 = 达一梯；二梯 = 达二梯未达一梯；…；最后一段 = 未达最低线 |
| **临界生 · 冲** | 未达该线，名次在 (Nk, Nk+30] ✔ |
| **临界生 · 保** | 已达该线，名次在 (Nk−40, Nk] ✔ |
| 冲线生归属 | 每个未达线的人只归「上面最近那条线」；「差 X 名」= 名次 − Nk |
| **班级进退步** | 每人百分位 P =（N − 名次）/（N − 1）×100，班级取平均；Δ = 本次 − 上次 ✔（用百分位抵消各次参考人数不同） |
| 「N 进 M 退」 | Δ ≥ +1 进，≤ −1 退，其间持平；**计数和图例用同一个取整后的 Δ** |
| 学生退步 | 退 X 名 = 本次名次 − 上次名次（按考号对齐），每班取最大 3 人 |
| 班级处方·重讲 | 班级题得分率 − 年级 ≤ −10，取最负的 ≤ 3 题，**排除补漏题** |
| 班级处方·保持 | 高于年级 ≥ 5 的最多 2 题；没有就整行不出 |
| 班级处方·补漏 | 本班得分率最低的一题；名单 = 该题得分 < 60% 满分的人；0 分人数 > 0 才写「其中 0 分 N 人」 |
| 共性问题 | 给分点级：按「共丢分」（不是人数）降序取前 6 |

## 4. 文案规矩
1. 页标题 = 结论或读图方法，数字进标题：「这次考得怎样：均分 87.4（满分 150）」。
2. 每张图的小字交代怎么读：「绿＝比年级好，红＝比年级差」「冲＝线后 30 名、保＝线前 40 名内」。
3. KPI 副标题写阈值不写形容词：「≥120 分」「≤60 分」。
4. 处方 = 动词标签（只用 重讲 / 盯人 / 补漏 / 谈话 / 保持）+ 粗体对象 + 数据 + 动作：「补漏　第 10 题·二次函数图象与系数　本班得分率最低：不到 60% 的 35 人（名单在右上角）」。
5. 共性问题「差在哪」≤ 20 字，点名具体错误，禁用「粗心 / 马虎 / 没掌握」。
6. 不下价值判断，不点名批评班级或老师；班名一律显示名，重点班标「重点」。
7. 数字格式统一：1 位小数，负号 U+2212。
