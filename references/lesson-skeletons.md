# 课型的页面骨架（都已在真实课堂验收）

## 先查表定课型（不许自己判断）

| 条件 | 课型 | 开头 | 计时 |
|---|---|---|---|
| 某概念第 1 课时 | 新授（第 1 课时） | 三情境汇聚导图 | 合计 1200 |
| 同一主题第 2 课时及以后 | **新授（续）** | 回顾步进页，或例 1 配「上节课 → 改一处」变式条 | 合计 1200 |
| 素材全是学生做过的题组 / 课后题，要归类 | **专题课（回看）** | 基准方法套路页 | **无** |
| 有成绩表、讲卷子 | 讲评课 | 成绩全景 | 无 |
| 讲给老师听 | 微论坛 | 课标 + 考情 | 可选 |
| 给老师看成绩 | 成绩分析报告 | KPI 看板 | 无 |


| 课型 | 开头 | 中段 | 收尾 | 页数 |
|---|---|---|---|---|
| **新授课** | 从情境抽象出概念（三情境汇聚导图 + 小动画） | 定义三卡 → 判定/决策表 → 例题步进 → 练习 → 方法页 → 练习 → 套路页 → 练习 → 实验台 | 易错八卡 + 总结揭晓 | 14–16 |
| **训练课 / 微专题** | 解题主线横排流程图（四步可展开）+ 速查表 + 核心技巧页 | 每题先练（计时）后讲（步进/推导器 + 结论条） | 易错 + 总结 | 16–22 |
| **复习课** | 可折叠知识网络 + 路线图 | 按块「速查卡 → 练 → 讲」 | 易错 + 总结 | 20–36 |
| **应用课** | 回顾两问 + 三卡（问法→动作） + 四步 SOP | 每类套路一页（设/式/范围/反套路/图）→ 练（计时）→ 讲（步进 + 图）；实验台按需 | 易错 + 总结 | 13–16 |
| **练习 / 考试讲评课** | 成绩全景（班均分 + 小问得分率） | 按试卷题号：高分选择题速查卡 → 低分题单题步进 + 图 → 大题每小问一页（计算拆推导页）→ 误区实验台 → 对照表 → 错在哪 | **易错八处**（无总结页） | 20–30，**无计时器** |

讲评课的完整规矩（数据、名单隐私、每题讲法）见 `review-lesson.md`；各科做法见 `subjects/*.md`；可照抄的示范是 `demo/review/`。

## 新授课（示例：某概念第 1 课时）
```
1 封面
2 从哪来：三情境 → 同一个式子（conv 导图 + 三个 .sc-fig 动画）
3 定义：三条件卡（fx-hero + fxgrid + fx-warn）
4 怎么判定：决策表（dec）
5 例题辨析（q 步进，无计时）
6 同步练习（q + 计时）
7 方法页：依据 + 推导器 + 技巧条
8 同步练习（计时）
9 例题建模（q 步进 + 图）
10 练习（原图叠高亮 + 计时）
11 变式 / 套路页 + 底部 SOP 条
12 练习（计时）
13 实验台（机动）
14 易错八卡
15 总结（揭晓）
```
练习计时四页合计恰好 1200 秒。

## 训练课 / 微专题
```
1 封面 · 2 主线四步 flow 导图 + dec-tip · 3 速查五式（关键一步黄底）· 4 核心技巧 tp 页 · 5 实验台（机动）
6… 逐题：先练页（题干 + 计时 + 一句提示）→ 讲解页（q 步进 或 推导器 + 结论条）
倒二 易错八卡 · 末 总结揭晓
```

## 复习课
```
1 封面 · 2 知识网络（四枝可折叠）· 3 路线图（flow）
每块：速查卡 → 练（计时）→ 讲（步进 + 图）
倒二 易错八卡 · 末 总结揭晓
```

## 应用课
```
1 封面 · 2 回顾两问 + 三卡 · 3 四步 SOP 套路页（tp）
每类：例题方法页（推导器 + 结论 + 技巧条）→ 练（计时）→ 讲（q + 图）
实验台（按需）· 倒二 易错 · 末 总结
```

## 页数与计时的算法
- 一页只做一件事；一页塞不下就拆，不缩字。
- 计时器：练习页 2:00–6:00 一档，合计恰好 20:00；讲解页不计时。
- 实验台按必要性放，不凑数。

## 新授（续）· 专题课（2026-09 三节数学验收课补充）

**新授（续）**：开头不用三情境导图，用「上节课的题改一处」——第一页就是例 1，上方一条变式条「上一题 → 改了什么 → 变成」。
**练习页三种写法**（默认第一种）：
1. 练讲合页：同一页有计时器 + 解法，计时到了再点「查看分析」（多数）；
2. 合页 + 细讲页：同一道题再拆 7 步细讲，图加高；
3. 纯练习页（只有大字题干 + 计时 + 页底提示条）+ 讲解页：只给压轴真题。
**方法页不是必需**：推导器只演「变形链本身就是考点」的内容（配方、因式分解）；含参分段、面积计算一律用步进页，每步一句话 + 一个式子。

**专题课（回看）**：
```
1 封面（chip「第 X 章 · 专题」）
2 基准方法套路页（tp）
每档一章：比基准简单 → 和基准一样 → 比基准难；档内每题每小问一页讲解步进（第一页完整题干，之后缩略题干，已求出的写进题干）
   q-aside 固定「为什么比基准简单 / 一样 / 难」；标准做法那一档插 1–2 个实验台
倒三 三档对照表 · 倒二 易错八卡 · 末 总结揭晓
约 20 页，无计时器，题号保留原号
```
