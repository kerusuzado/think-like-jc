# 练习 / 考试讲评课（第五种课型）

来源：2026-09 五科「九上 9 月练习讲评」（化学 23 页 / 物理 25 页 / 语文 27 页 / 英语 23 页 / 历史 30 页），全部经主编、老师验收。
这份文件把五节课共同的做法写成照做清单；各科特有的做法见 `references/subjects/*.md`。

> 讲评课和新授课的根本区别：**新授课讲「这个知识是什么」，讲评课讲「这张卷子上，多少人、错在哪一步、为什么、下次怎么不错」。**
> 每一页、每一步都要落到本卷的真实数据上。数据不是模型编的，是老师给的成绩表算出来的。

## 0. 开工前必须问老师的事（只许问，不许猜）

1. **成绩表**：要一份逐人逐小问的得分表（Excel 另存 CSV），格式见 `scripts/review_data.py` 顶部。选择题格子最好是学生选的字母（这样才有选项分布）。
2. **小问怎么切**：`13(1)①` 还是 `13(1)`——全课只用一种写法，表头就是它。
3. **阅卷记录**：主观题「学生写了什么错」「多少人写『偏小』」这类数字成绩表里没有，只能来自老师的阅卷记录。**没有就不写人数**，写「常见写法」。
4. **老师看原卷判的题**（默写、附加题）：成绩表里没有，课件里明写「老师看原卷判，本页只对答案，不列人数」。
5. **名单能不能进课件**：「本题错的人」要把全年级姓名嵌进 HTML。问清楚：要不要？只在教师机上用？
6. 机构名、署名、年级、考试名称、题目出处——照旧只问不猜。

## 1. 骨架（按试卷题号走，不按知识点重排）

```
1 封面（hero ≤ 6 字，如「化学试卷讲评」；副标题「2026 学年九上 9 月练习」）
2 成绩全景：左 各班均分条（细竖线 = 年级均分）；右 各小问得分率条（< 50% 红，注「今天重点讲」）
  小问 > 36 个时右边改热力格（R.overview() 自动切）
按试卷板块，每块：
  ├ 高得分率选择题（≥ 80%）→ 速查卡页（H07）：一页 3～4 张，▶ 一张一张揭
  ├ 低得分率 / 要画图才讲得清的题 → 单题步进页（q + 右侧图 + 图上高亮）
  ├ 大题：每个小问（或两个短小问）一页；计算小问拆出推导页（exq + 推导器 + 结论条）
  ├ 丢分最集中的点 → 误区实验台「拖一拖」（只复现错得最多的那一个）
  ├ 易混概念 → 对照表页（▶ 一行一行揭）
  └ 丢分最重的大题 / 板块末尾 → 「错在哪（学生原话，不带姓名）」四卡 + 记住这一类
末页：「这张卷子最容易丢分的八处」（易错八卡，按丢分人数从多到少）
```
- **没有计时器**（`write_pages(P, timers=0)`，`audit --type review`），**没有总结导图**——易错八处就是收尾。
- 页数：一般 20～30 页。每个题型「整组 1 页 + 专页 0～3 页」，不要每题都开专页。
- 专页怎么选：优先 < 50% 的小问（`R.report()` 会列出没讲到的低分小问），再加 1～2 道适合画图的。

## 2. 数字只从数据来

```python
from review_lib import Review
R = Review(os.path.join(HERE, "data.json"))      # scripts/review_data.py 成绩.csv lesson/data.json
R.overview()                                     # 成绩全景整页
R.rate_html("6") / R.rate_html(["13(1)①","13(1)②"])   # q-head 里的得分率（< 50% 自动红）
R.pick_html("6")                                 # 选项分布 A 56 · B 18 · C 8 · D 552（正确项绿底）
R.names_html(["13(3)"])                          # 「本题错的人」按钮
R.fill("选 C 的 {C} 人……{13(3).错} 人没拿满")      # 占位符 → 真实数字
R.quick([...]) / R.errs([...], keep) / R.q(q, ...)     # 速查卡 / 错在哪 / 单题页（见 page-types.md §讲评课）
R.report()                                       # 末尾：哪些小问讲到了，哪些低分小问漏了
```
- **文案里手敲的「N 人」会被 lint 警告**。选项人数、丢分人数一律 `{键.B}` `{键.错}`；只有阅卷记录里「写了什么」的人数才手写，并且要和老师给的记录逐字对上。
- 同一个数字在步骤、错因卡、易错八处出现多次时，三处必须一致——用同一个占位符就自动一致。
- 得分率 < 50% 红（`jp-low`），否则绿（`jp-ok`），`rate_html` 自动判。

## 3. 每道题怎么讲（五科共同的顺序）

**页标题 =「第 N 题 · 考点：一句话点破方法或陷阱」**（≤ 26 个全角字，只许一行），例：
「第 6 题 · 分类：每一组逐个过，一个不对整组就错」「第 4 题 · 谁推动谁：箭头的方向别画反」。
kicker =「第 1～12 题 · 选择」这类题号范围 + 板块名，范围要盖住本页所有题号。

**选择题单题页（4～6 步）**：
1. 抓题眼 / 信号（材料关键词、空格前后的词、题干限定词「不正确」「物理性质」）；
2. 正确项：点出它和材料 / 规则对上的那个词，`→ <span class="ans-in">D</span>` 收尾；
3. **错得最多的那一项**加 `!`（红步），写「{B} 人选 B：错因」——错因必须点名概念区别，不许写「粗心」「没掌握」；
4. 其余错项一句话一起划掉；
5. （可选）同类归纳 / 方法口诀，或「拖下一页的实验台看」。

**速查卡（H07）固定三行**：思路（通用方法）/ 关键（定答案那一步 → **字母**）/ 易错（最多人选的错项 + 人数）+ 选项分布。

**主观题**：先说给分口径（「分三块，各 1 分、独立给分」）→ 每块答案 → 每块丢分人数 + 常见错写 → 学生原话逐块判「得 N / M 分」（`.jp-blocks` + `.jp-stack`）→「答题时可以直接分三句写」。

**计算题**：讲评页只说思路，「（下一页推）」；推导页 = 题干条 + 推导器（单位换算那一步 `role:"hl"` 黄底，sub 写「黄底 = …」）+ 结论条（`.reveal-after`，写错写值、人数、差几倍）。

**错在哪四卡**（`R.errs`）：学生写的（原话，用「」，一字不改，不带姓名）/ 错在哪（点名概念或题目限定词）/ 应该写（完整标准句）+ 人数；页底「记住这一类」一句口诀。

## 4. 讲评课特有的硬规则

1. **名单隐私（主编 2026-09-27，一条不许改）**：默认收起；选了班、点了按钮才出姓名；全年级只报各班人数；选班全课同步并记住；离开这一页自动收起。姓名只在 data.json，页面文字里一个都不许有（lint + audit 双查）。
2. **data.json 永不提交**（`.gitignore` 已带），交付时告诉老师「文件里含学生名单，只在教师机上用」。
3. **图上高亮不累积**：引擎每一步只点亮这一步 `@键@` 里列出的组，上一步亮的会灭。要一直亮着的（已经揭出的答案、底图框），**后面每一步都要把它的键带上**：`@a1x a1@` → `@a1x a1 a2x@` → `@a1x a1 a2x a2@`。
4. **一页一个步进组件**：`.q` / 推导器 / 速查卡 / 逐条揭 / RD / 对照表 / 分拣台……一页只放一个（后注册的会顶掉前一个，audit `drivers2`）。
5. **小问键三处逐字一致**：成绩表表头、`data-subs`、q-head——写错一个字名单就静默变空（lint 查 data-subs）。
6. **作文 / 满分几乎没人拿到的题不放「本题错的人」**（会把全年级列出来）；改成档次热力表。
7. **重画的图要在 figcaption 声明依据**：「按原图数据重画」「装置重画；刻度按真实体积」「刻度按真实年数：一格 100 年」「示意，不按比例」。
8. **材料有删节要说**：「只摘答题用到的句段；全文请对照试卷原卷」。
9. **模型自编的内容标「待科组审」**（英语搭配例句、历史课本页码拿不准时）。
10. 学生面前不提「原件」「参考答案错了」；卷面有错只进给老师的意见清单。

## 5. 讲评课新页型速查（写法见 `page-types.md` §讲评课，组件在 `--pack review`）

| 页型 | 组件 | 用在 |
|---|---|---|
| 成绩全景 | `R.overview()` | 第 2 页 |
| 速查卡 | `R.quick()` → `.h7-quick` | 高得分率选择题 |
| 单题步进 + 图 | `R.q(q, …)` + `.jp-fig` + PH 画图 | 低分题、要画图的题 |
| 文本图（原文 / 材料 / 范文当图） | `.jp-fig.jp-text` + `.th.hl`（句子变黄）/ `.tr.hl`（按步现身） | 语文、英语、历史材料题 |
| 跟题运镜 | 文本图再加 `.jp-cam-on` | 原文长、字小时 |
| 得分块 + 原话逐块判 | `.jp-blocks` + `.jp-stack > .jp-smp` | 所有主观题 |
| RD 原文 + 逐题卡 | `.rd` | 英语阅读 / 完形 / 语法选择，语文、历史材料选择 |
| 逐条揭 | `.jp-seq > .jp-si` / `.st-wrap > .st` | 默写答案、升格对照、拼写对比 |
| 对照表 | `.jp-rv > table.jp-cmp > tr.rv-i` | 易混概念 |
| 选项逐项核对 | `.jp-jo` | 材料型选择题（材料没说 / 与材料矛盾 / 只说一半 / 说了 ✓） |
| 点选看依据 | `.jp-chipbar` | 概括观点、找依据 |
| 换一换 | `.jp-fix` | 病句关联词、选词填空 |
| 分拣台 | `.jp-sort` | 把学生原话分进「给分 / 不给分」 |
| 翻卡 | `.pv-wrap` | 俗语、字面 vs 意思 |
| 要点勾选表 | `.ck-wrap` | 作文 / 主观题要素计分 |
| 错在哪 | `R.errs()` | 大题 / 板块末尾 |
| 误区实验台 | `.lab` + `.ro-good.jp-bad/.jp-neutral` | 复现错得最多的那一个点 |
| 易错八处 | `.wrgrid` | 末页 |

## 6. 注释里的「日期 + 来源 + 编号」

五节课的代码注释里有这样的标记：`（主编 09-27）`、`（09-28 老师建议）`、`（09-28 主编 J3）`、`（照 H07）`。
含义：MM-DD 是意见日期；「主编」管交互和隐私，「老师建议」管投屏可读性；J2/J3 是那一轮意见清单的条目号；H07 是被照着做的已验收课件编号。
**规矩**：按意见改的代码，注释写「（日期 来源 编号）+ 一句完整规格」；**这些行为不许回退**（放大镜常驻可拖、大字档、点选放大、名单五条、跟题运镜）。
