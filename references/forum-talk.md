# 微论坛 / 备课讲解（第六种场景：讲给同行老师听）

来源：2026-09「微论坛 · 实际问题与二次函数 · 反比例函数起始课」验收版（39 页）。
**受众是备课组 / 科组老师**（可能有教研员）。和学生课件的根本区别：

| | 学生课件 | 微论坛 |
|---|---|---|
| 语气 | 对学生说，短句大白话 | 谈「学生」：「引导学生形成…」「发展模型观念与应用意识」；教研术语可用 |
| 密度 | 一页一件事，大字 | 表格为主，一页 9–12 行，字小一档 |
| 引用 | 几乎没有 | 课标写到页码；文献按「作者.(年). 篇名. 刊名, (期), 页.」；每道题标出处 |
| 「原件」 | 禁用 | **必须用**：「原件如此」「原资料只给结果，此处为备课补写」 |
| 收尾 | 易错 + 总结 | 学习层级表 + 谢谢聆听（满版校园照） |

## 0. 开工前问（整理成一张意见清单）

| 要问的 | 没给时 |
|---|---|
| 科组、年级、学科、主讲署名、日期周次 | **不许猜**，留空等回复 |
| 覆盖哪几章哪几课时 | 必须给 |
| 论坛时长（决定每课时几页） | 必须给 |
| 课标页码 + 已涂黄的截图（或文字摘录） | 无截图 → 文字摘录 + 标出本次条款，页码只写用户给的 |
| 近几年中考统计（年份 / 题号 / 考点 / 分值） | **不许自己统计、不许凭记忆**；没给就删这页 |
| 教辅名称、要不要逐题核对 | 不做就删核对清单 |
| 每课时的精选题（出处 + 题干 + 原图） | 只用给的题；答案自己逐步重算 |
| 参考文献 | **只许用用户给的；没给就不放文献，绝不编** |
| 学情数据 | 没给就不写学情 |

## 1. 骨架（照公式算页数）

```
封面（chip「九年级数学科组 · 微论坛」；hero「备课讲解」；副标题 = 单元名，每单元一行；署名两行：范围 / 主讲 + 日期）
课标原文（两张扫描图并排 + 脚注「黄色为本次涉及条款…」+ [1] 课标文献）
[有数据] 考情统计表（近 N 年；未核实的写「待核」；脚注写来源 + 一句结论）
单元导图（每单元一页，枝 = 课时，每枝 4 叶 ≤ 14 字；老师听众不遮挡叶子）
[要做] 教辅核对清单（四类标签：事实 / 口径 / 提醒 / 存疑；每页 ≤ 12 行）
每课时四件套：
  ① 知识点 × 难点表（标题前「#26-13」；3–4 个知识点，每个 1–3 个难点，难点 = 动作 + 对象）
  ② 关键点图解（标题「课题 · 关键点图解：观点一句」；2–3 张卡 = 图 / 表 + 一句说明；底部口诀条「X 问题三步：… → … → …」）
  ③ 教学建议 5 条（情境导入 → 课件互动 → 表格 / 流程支架 → 追问对比 → 评价 + 素养）+ 文献 5 篇（编号全课连续）
  ④ 精选题 1–2 道（教辅 / 课本原题 + 本市真题或区模拟；出处 + 学习层级；分析 → 解 → 答 → ★易错 ×2；讲评提示写出处诚信或追问）
学习层级划分表（每单元 6–7 层：了解 → 理解 → 掌握 → 运用 → 综合运用；脚注列「题目 → 层次」）
结尾页（谢 谢 聆 听 + 科组 + 主讲）
```
每课时页数按时长：≥ 35 分钟 → 四件套 + 精选题 2；20–35 → 精选题 1；< 20 → 只留 ①②（建议合进口诀条）。

## 2. 硬规矩
1. 标题就是观点：「面积问题 · 关键点图解：先数边，再看范围」。
2. 证据先于判断：数据写来源、未核实写「待核」；结论句从证据来。
3. 精选题上每个「层次 N」都要在学习层级表里找得到（层级闭环）。
4. 精选题的解答**不能犯核对清单里自己点名的毛病**（原 deck 就犯了一次）。
5. 易错点名具体动作：「3.564 精确到 0.1 四舍五入成 3.6；最大安全限高必须向下取 3.5。」
6. 教学建议里提到的「课件互动」是主讲人自己的学生课件，**不必做进本 deck**。
7. 计时器可选（默认每道精选题一个）。
