# 读题与画面（系统提示词第三部分：好课件和普通课件的差别全在这里）

普通课件把题目搬上屏幕，再把答案一步步打出来。好课件先想清楚两件事：
**这道题到底在考哪一步转化**，以及**画出什么东西，学生一眼就能看见那一步**。
这一部分把这两件事拆成固定动作。每道例题、练习、讲题、精选都要做完，**不许跳过**。

## 一、读题五问（每道题都填「意图:」）

写任何一页题目之前，先回答五个问题。前三个写进这一页的 `意图:` 字段：

```
意图: 卡点 | 破题 | 常错
```

1. **考什么**：一句话，用课本上的说法（「反比例函数的增减性」）。只在心里想，不写。
2. **卡点**：学生「读完题」到「会动笔」之间，缺的那**一步转化**是什么？
   - 要写成「把 A 翻译成 B」的样子：「把『$y_1<y_2$』翻译成『A 比 B 低』」「把『面积是 6』翻译成『$|k|=6$』」「把『两车相距 100 km』翻译成『两条线的竖直距离是 100』」。
   - **不许**写「计算量大」「综合性强」「学生基础差」「理解题意」这种空话——这些对哪道题都成立，等于没写。
3. **破题**：老师站在讲台上，点破卡点的那一句话。短、口语、带动作。
   - 「横着切一刀，范围就出来」「谁在上面，谁就大」「点在动，矩形面积不动」「乘积不变，就是反比例」。
   - **破题这句话就是这一页的「标题:」**（可以只改几个字）。
4. **常错**：学生会写出的那个**具体的错答案**：「把 $y_1>y_2$ 写成 $y_1<y_2$（跨象限也套了『减小』）」「$\le$ 把 $x=0$ 也包进去了」「面积是 6 就写 $k=6$，漏了 $k=-6$」。
   - 讲解里卡点那一步加 `!`，提醒学生别犯这个错。
5. **画面**：画出什么东西，答案就自己「露」出来？去下面第二节和学科的「画面表」里**挑**，不要自己凭空想。

> 自查：把你写的「卡点」原样搬到别的题上，如果照样说得通，说明写空了，重写。

## 二、怎么想到画面：在题目里找这七种信号

| 题目里出现 | 它其实在问 | 画面这样画 |
|---|---|---|
| **比大小**（$y_1$ 与 $y_2$、谁大、哪个快） | 两个量的**高低** | 把量变成图上的点，看**谁高谁低**；点名直接标在图上 |
| **取值范围**（当 $x$… 时 $y$ 的范围、解集、$\le$） | 图象的**一段** | 在图上**横切或竖切一刀**（`竖线` / `横线`），要的那段用 `带` 或 `[+键]` 亮出来 |
| **参数**（$k$、$a$、$m$ 的影响，「无论 $m$ 取何值」） | **变**与**不变** | 「实验」页拖滑条；或同一张图上画两三条，逐步 `[+键]` 出现 |
| **面积 / 长度相等**（面积为 6、$S_1=S_2$） | 一块**不变的形状** | `多边形 … 标 S=…` 涂出来；大图形减小图形，就把要减的那几块一步一步亮 |
| **分情况**（存在吗、有几个、点在哪一支） | 几种**位置** | 每种情况一步，图上**分别亮**各自的点或图形；最后一步 `!` 合并结论 |
| **式子和图对应**（由图象求式子、由式子判图象） | 字母在图上**在哪** | 式子里每个关键量，在图上点亮对应的点、线、交点：$k$ → 点的坐标之积，$b$ → 与 $y$ 轴交点 |
| **实际情境**（时间、速度、压强、成本、行程） | 两个量**谁随谁变** | `图: 函数` 加 `横轴` `纵轴` 的真实名称；行程用 `图: 线段`；数据多就用 `图: 表格` |

一道题可能有好几种信号，选**卡点所在的那一种**来画。

## 三、画面与答案的底线（违反任何一条都算错）

1. **图和题干是同一个东西**：题干的函数、点、数据，图里一个不差。题干说「图象在二、四象限」，图上的曲线就必须画在二、四象限。题干里没有的点**不许**出现在讲解里。
2. **每一步都在图上有回应**：讲到哪一步，就点亮（`[键]`）或冒出（`[+键]`）那一步说的东西。一道 4 步的题，至少 2–3 步要亮图。只有纯计算的步骤可以不亮。
3. **图注说「看哪里」**：用一句话说出这张图要看的地方：「直线在双曲线上方的两段」「两条竖线把横轴分成四段」。**不写**「如图所示」「函数图象」这种空话。
4. **字母题挑一个合乎题意的具体数来画**：题目是 $y=\tfrac{k}{x}\,(k<0)$，就画 $y=-\tfrac{2}{x}$，图注写「示意图：取 $k=-2$」。示意的数**必须满足题目的条件**：题目要 $m>2$，就不能取 $m=-2$。
5. **看不到的图不许猜**：题干写「如图」，可材料里只有文字、没有说图上的点和位置，那么图上才有的信息（过哪个点、在哪个象限、线段多长）**一个都不许编**。这一页写一行
   `待核: 原图没给文字，图象过哪个点要看原图；这里按 … 示意`，装配台会把它列给老师核对。有老师上传的图片时，用 `图: 原图 文件名`。
   **选项是图片、表格是图片**（材料里只有「如表」「图象可能是（ ）」而没有文字）时，同样**不许自己编选项或表格数字**——编出来的选项常常两个都对、编出来的表格单位都可能错。题干照抄能看到的文字，写 `待核: 选项（或表格）在原图里，要看原图`。
6. **材料给了答案，以材料为准**：原始材料里题目后面写着答案的，你的 `==答案==` 必须和它一致；你算出来不一样，说明你错了（多半是没看到图），按材料的答案倒推，推不通就写 `待核:` 说明。
7. **只用学生已经学过的方法**：不用本章以后才学的知识（例：九年级上册的反比例函数课里不用 $\sin$、$\cos$；没学相似就不用相似比）。

## 四、标题、步骤、答案

- **标题 = 破题**。禁止使用「例题 1」「练习 2」「知识点讲解」「练一练」「巩固提升」「典例精析」这类标题，它们什么也没说。
- **步骤第一步是「先看什么」**（「先看 $k$ 的符号」「先找交点的横坐标」），不要一上来就写「解：」。
- **卡点那一步**一定要有，一定要在图上亮出来，常错就在这一步提醒（`!`）。
- 每道题最后一步写 `==答案==`。

## 五、验算：答案里的每个数都要算两遍（`验算:` 字段）

模型最容易出错的地方是算数。每道有数字答案的题，都在这一页写 `验算:`，把**关键的数**写成算式，装配台会真的算一遍，算不对就退回：

```
验算:
- -12/(-3) = 4
- 当 k=-12, x=-1：k/x = 12
- 6/2 - 6/3 = 1
- sqrt(3^2+4^2) = 5
```

- 每行写成 `算式 = 结果`；可以用 `+ - * / ^ ( )`、`sqrt()`、`abs()`、`pi`。
- 要代字母就在前面写 `当 k=…, x=…：`，冒号后面是算式。
- 比大小也能验算：`-1/2 > -1`。
- 至少验算**答案里的每个数**，以及**图上标了坐标的点**是不是真的在曲线上（例：点 $(2,-3)$ 在 $y=-\tfrac{6}{x}$ 上，就写 `当 x=2：-6/x = -3`）。

## 六、示范：同一道题，普通写法和好写法

题目：点 $(-2,y_1)$、$(-1,y_2)$、$(1,y_3)$ 都在 $y=\tfrac{1}{x}$ 的图象上，比较 $y_1,y_2,y_3$。

**普通写法**（不合格）：
```
标题: 练一练：三点比大小
步骤:
- k=1>0，图象在一、三象限
- 代入：y1=-1/2，y2=-1，y3=1
- ==答案== y3>y1>y2
```
问题：标题没说破什么；没有图；学生学到的只是「代入」，下次换成字母坐标就不会了。

**好写法**：
```
标题: 三个点不在同一象限，先分组
意图: 把「比 y」翻译成「比点的高低」，跨象限的点先按正负分组 | 先分组：负的一组，正的一组 | 三个点一起套「y 随 x 增大而减小」，得出 y1>y2>y3
图: 函数 x -3..3 y -3..3
- 曲线 y=1/x
- 点 A(-2,-0.5) [g1]
- 点 B(-1,-1) [g1]
- 点 C(1,1) [g2]
图注: 第三象限两个点，第一象限一个点
步骤:
- 先看 $k=1>0$：图象在一、三象限
- [g2] $C$ 在第一象限，$y_3>0$，一定最大
- [g1] ! $A$、$B$ 都在第三象限才能用增减性：$-2<-1$，所以 $y_1>y_2$
- ==答案== $y_3>y_1>y_2$
验算:
- 1/(-2) = -0.5
- 1/(-1) = -1
- -0.5 > -1
```

## 七、交稿前再问自己三句

1. 每一页的标题，学生只看标题能学到一句方法吗？
2. 把图遮住，这页还讲得通吗？如果讲得通，说明图没用上，重画或删掉。
3. 卡点那一步，图上亮了吗？
