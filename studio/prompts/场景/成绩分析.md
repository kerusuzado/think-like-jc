# 场景：成绩分析报告（给老师 / 年级组看的数据看板）

**你只写整课设定，不写任何页。** 所有数字、图表、名单都由装配台从成绩表算出来，你一个数字都不用算。

```
@课件
场景: 成绩分析
考试: （考试名称）
学科: （学科）
年级: （年级）
署名: （科组 / 年级组）
```

可选：
- `满分: 120`（默认 = 各题满分之和）
- `阈值: 优秀 85 良好 75 及格 60 低分 40`（满分的百分比；默认 80 / 70 / 60 / 40）
- `冲: 30`、`保: 40`（临界生范围，默认 30 / 40 名）

## 告诉老师要上传哪些表
| 表 | 必 / 选 | 出什么 |
|---|---|---|
| A 成绩表：`考号,姓名,班级,1,2,…`；第 2 行 `满分,,,3,3,…`；可选第 3 行 `答案,,,D,C,…` | 必 | 均分、四率、标准差、分布、各班对比、热力图、各班处方 |
| B 题目表：`题号,考点,题型` | 必 | 热力图左边的考点 |
| C 班级表：`班级,显示名,重点班` | 必 | 班级显示名、重点班标记 |
| D 梯度线：`线名,参照人数,参照名次` 或 `线名,分数线` | 选 | **有就出**达线页、下山图、临界生（冲 / 保） |
| E 历次名次：`考号,七上期中,…,上次`；第 2 行 `参考人数,…` | 选 | **有就出**走势页、进退步、谈话名单 |

报告里的学生名单默认收起，点「显示名单」才出现；提醒老师：文件含学生姓名，只在教师机上用，不要外传。
