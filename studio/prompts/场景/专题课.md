# 场景：专题课（一类题 / 一种方法的归类课，例题和练习计时合计 20:00）

适用：老师说「专题」「微专题」「复习一类题」「把这几道题归类讲」。
专题课可以用「例题」和「练习」两种题目页；**每道例题、练习都写 `计时:`，全课合计正好 20:00**（例题一般 3:00–3:30，练习 1:00–3:30）。

## 排页（8–14 页）
```
@页 决策            拿到题先问哪几句（判断属于哪一类）
@页 套路            通法三步 + 反套路 + 一张代表图
@页 例题            例 1：最典型的一道（变式条可省）
@页 例题            例 2：`变式:` 从例 1 改一处（条件 / 问法 / 图形）
@页 例题            例 3：再改一处，或综合
@页 推导            （可选）关键变形单独演示
@页 实验            （可选）拖一拖：参数变化时分类的分界
@页 对照            几种类型放一起比：类型 | 特征 | 方法 | 常见错
@页 易错            （可选）8 条
```
- **变式链**是专题课的灵魂：每道例题都用 `变式:` 说清「上一题 → 改了什么 → 变成」，让学生看到题是怎么「长」出来的。
- 例题优先用老师给的题（课后题、练习册、学生做过的错题）；自编题要自己完整做一遍。
- 收尾用「对照」表把几类题并排比，`记住:` 一句口诀。
