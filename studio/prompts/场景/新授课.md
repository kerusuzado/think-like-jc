# 场景：新授课（40 分钟，学生练习约 20 分钟）

## 第 1 步：定课时类型
| 情况 | 开头怎么做 |
|---|---|
| 这个概念的**第 1 课时** | 「三卡」或「图解」从 2–3 个生活情境 / 旧知引出新概念 |
| **第 2 课时及以后**（老师说「续」「第二课时」，或课题是上一课的延伸） | 第一道例题加 `变式: 上节课的题 | 改了什么 | 变成`，从旧题改一处引出新内容 |

## 第 2 步：排页（12–16 页，照这个顺序填）
```
@页 三卡 / 图解      从哪来：情境 → 概念（第 1 课时）
@页 三卡            定义 / 公式 + 三个要点
@页 决策            怎么判断 / 怎么选方法（有「判断」「分类」的课才要）
@页 例题            例 1：最基础的用法，步骤 3–5 步，配图（计时）
@页 练习            练习 1（计时）
@页 推导 / 例题       方法页：变形过程本身是考点就用「推导」，否则用例题
@页 练习            练习 2（计时）
@页 例题            例 2：提升一级（建模 / 综合），配图 + 点亮（计时）
@页 练习            练习 3（计时）
@页 套路            这类题的三步套路 + 反套路
@页 练习            练习 4（计时）
@页 实验            （可选）拖滑条看变化：参数影响图象、比例、速度……
@页 易错            易错 8 条
@页 总结            知识骨架导图（2–4 枝）
```
- **例题和练习都计时，全课合计正好 20:00**（老师常让学生先做例题再讲）。例题一般 1:30–3:30，练习 1:00–4:00，按题量定；例：例题 2:30 + 3:00，练习 2:00 + 3:00 + 2:30 + 2:00 + 2:30 + 2:30。
- 知识页、套路页、实验页（没有让学生动笔的题）、易错、总结**不计时**。
- 章节 3–5 个，建议：`从哪来 | 是什么 | 怎么用 | 易错与总结`，按课题改名。

## 第 3 步：每页怎么写
- **例题**：题干用课本 / 老师给的题；步骤 = 老师在黑板上讲的顺序；和图对应的步骤写 `[键]`，图里对应的线、点、区间写同一个 `[键]`。
  - 高亮**不累积**：每一步只亮这一步写的键。要一直亮着的，后面每步都带上它的键。
- **练习**：题干 + `计时:`；可以写 2–4 步简要答案（学生做完再揭），也可以不写步骤。
- **例题**也写 `计时:`，再写完整步骤。
- **答案放进步骤里**：最后一步用 `==答案==` 包住结果（会显示成答案胶囊）；不要把答案写在题干或页面上直接露出来。
- **推导**：只在「怎么变形」是本课重点时用（配方、解方程、化简、公式推导）。每行一个式子，2–6 行。
- **易错**：8 条都要**具体**（点名写错成什么样），不写「粗心」「计算错误」。
- **总结**：叶子是学生要能自己说出来的关键词，每片 ≤ 12 字。

## 各科开头参考
- 数学：情境 → 数量关系 → 式子；或旧知识改一处。
- 物理 / 化学 / 生物：生活现象或实验现象 → 提问 → 概念。
- 语文：一句原文 / 一个画面切入（「图: 原文」+ 点亮句子）。
- 英语：情境对话 / 图片 → 目标句型；词汇页用「对照」（词 | 意思 | 例句）。
- 历史 / 道法 / 政治：一则材料 / 一个时间点（「年代轴」）→ 问题。
- 地理：一张示意图（能画成柱状、折线、流程就自己画；地图必须用老师给的图）。
