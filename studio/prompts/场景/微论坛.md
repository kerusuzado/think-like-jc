# 场景：微论坛（讲给同行老师听的单元备课分析）

## 开工前要的材料（没给就不做那一页，绝不编）
| 材料 | 没给时 |
|---|---|
| 科组、年级、学科、主讲 | 不猜，留空让老师补 |
| 覆盖哪几课时、论坛时长 | 必须问 |
| 课标原文（截图或文字） | 不做「课标」页 |
| 近几年中考 / 高考统计 | 不做「考情」页 |
| 教辅名称、要不要核对 | 不做「核对」页 |
| 精选题（出处 + 题干） | 只用给的题，答案自己重算 |
| 参考文献 | 不放「文献」，绝不编 |

## 排页
```
@页 课标            课标原文（截图或摘录）
@页 考情            近 N 年考情（脚注写来源；没核实写「待核」）
@页 导图            单元知识结构（枝 = 课时，每枝 3–4 叶）
@页 核对            （要做才有）教辅问题清单
每课时四件套：
  @页 难点          核心知识点 × 难点（难点 = 动作 + 对象）
  @页 图解          关键点图解：2–3 张图 + 一句说明 + 口诀
  @页 建议          教学建议 5 条（+ 老师给的文献）
  @页 精选          精选题 1–2 道（出处 + 学习层次）
@页 层级            学习层级划分（精选题标的层次都要在这里）
```
- 装配台自动加「谢谢聆听」结尾页。
- 听众是老师：导图叶子直接显示；标题是观点句（「面积问题：先数边，再看范围」）。
- 每课时页数按时长：≥ 35 分钟四件套 + 精选 2 道；20–35 分钟精选 1 道；< 20 分钟只留难点 + 图解。
- 精选题的解答不能犯「核对」页里自己点名的毛病。
- 没给课标原文时，「层级」页只按「了解 / 理解 / 掌握」分题，**标题和表格里都不许出现「课标」二字**，也不许写成像课标原话的句子（「知道……的意义」「能……」）；层级要求用自己的话说成学生能做到的动作。
