# 场景：讲评课（试卷 / 练习讲评，不计时）

## 开工前必须有（缺了就先向老师要，不许猜）
1. **成绩表**：逐人逐小问得分（老师在装配台上传）。表头题号就是你在课件稿里写的 `小问:` / `题N:`，一字不差。
2. **试卷内容**：题干、选项、答案（老师贴给你，或上传截图）。
3. （有更好）阅卷记录：学生常见错写。没有就写「常见写法」，**不写人数**。

## 排页（按试卷题号走，不按知识点重排；15–25 页）
```
@页 全景            这次考得怎样（只写标题，内容自动）
按试卷板块，每块：
  @页 速查          得分率高的选择题 3–4 道一页，三分钟对完
  @页 讲题          得分率低（< 50%）或要画图才讲得清的题，一题一页
  @页 讲题 / 推导     大题每个小问一页；计算过程是难点就加一页「推导」
  @页 对照          （可选）易混概念逐行对比
  @页 错因          丢分最集中的 2–4 类错：学生写的 | 错在哪 | 应该写
@页 易错            （可选）这张卷子最容易丢分的八处
```
- 装配台会提醒「得分率低于 50% 却没讲到的小问」—— 每个都要有一页「讲题」。
- 章节 = 试卷板块：`全景 | 选择题 | 填空题 | 解答题 | 错因`。
- 没有计时器，没有总结导图。

## 每道题怎么讲
- **页标题**：「第 N 题：一句话点破方法或陷阱」（≤ 20 字）。
- **选择题讲题页（4–6 步）**：① 抓题眼（关键词、限定词）→ ② 正确项为什么对 → ③ `!` 错得最多的一项：「{N.B} 人选 B：错因」（点名概念区别，不许写「粗心」）→ ④ 其余错项一句话划掉 → ⑤（可选）方法口诀。
- **速查卡**：`思路` 通用方法 / `关键` 定答案那一步 / `易错` 最多人选的错项 + `{N.X}` 人数。
- **主观题**：先说给分口径（分几块、各几分）→ 每块答案 → 常见错写 → 「答题时可以分三句写」。
- **错因**：「学生写的」用原话（不带姓名）；「错在哪」点名概念或题目限定词；「应该写」完整标准句。

## 数字规矩
- 人数、得分率一律用占位符：`{19(2).错}` `{19(2).率}` `{9.B}` `{人数}`。
- 不许写「大部分同学」「很多人」来代替数字；有数字就用占位符。
- 不写学生姓名。「本题错的人」名单由装配台自动放在讲题页右上角，默认收起。
