# 课件稿格式（给模型看的完整说明）

你写的不是 HTML，而是一份**课件稿**：纯文本，一行一个字段。装配台把它变成成品课件（排版、动画、公式、计时器、品牌全部自动）。
**只能用本文列出的页型和字段**，别的写法装配台不认识，会报错。

---

## 一、文件长什么样

```
@课件
场景: 新授课
学段: 初中
年级: 九年级
学科: 数学
标题: 二次函数 y=a(x-h)²+k 的图象和性质
大字: 顶点式
章节: 从平移说起 | 顶点式 | 用起来 | 易错与总结

@页 三卡 [从平移说起]
标题: 三个平移，一个口诀
……

@页 例题 [顶点式]
标题: 从顶点式直接读性质
……
```

- 第一行必须是 `@课件`，下面写**整课设定**。
- 每一页以 `@页 页型 [章节名]` 开头。`[章节名]` 必须是「章节:」里的某一个；同一章节连续几页，只在第一页写也行。
- 页与页之间空一行。`//` 开头的行是注释，装配台忽略。

## 二、整课设定（@课件 下面）

| 字段 | 必填 | 说明 |
|---|---|---|
| 场景 | ✔ | 只能是：新授课 / 专题课 / 讲评课 / 微论坛 / 成绩分析 |
| 学科 | ✔ | 语文、数学、英语、物理、化学、生物、历史、地理、道德与法治、思想政治…… |
| 年级 | ✔ | 如 九年级、高一 |
| 学段 | | 初中 / 高中 |
| 标题 | ✔ | 课题全名（成绩分析可不写） |
| 大字 | ✔ | 封面大字，**≤ 6 个字** |
| 章节 | ✔ | 3–5 个，用 ` \| ` 隔开，每个 ≤ 6 个字；它们就是目录和页右上角的小字 |
| 页眉 | | 每页顶栏右侧的小字，默认用标题 |
| 副标题 | | 封面大字下面一行 |
| 署名 / 署名2 | | 封面署名（如「数学科组」「主讲 王老师」） |
| 原稿题号 | 有原稿时必写 | 原稿（导学课件、学案）里一共有哪些题，如 `1-7`。装配台会逐题核对：每题要么被某页的「原题: N」用上，要么写进「删题:」 |
| 删题 | | 原稿里不用的题和理由，如 `删题: 5 和例2同类；8 超出本节进度`。没写理由会报错 |
| 小标签 | | 封面左上的小胶囊，默认「年级学科 · 场景」 |
| 考试 | 讲评课、成绩分析必填 | 考试名称 |
| 满分 / 阈值 / 冲 / 保 | 成绩分析可选 | 见「成绩分析」一节 |
| 主讲 / 科组 | 微论坛 | 结尾页署名 |

## 三、通用写法

**字段**：`字段名: 内容`（中文冒号也行）。只有本页型认识的字段名才算字段；正文里出现「验：」「解：」之类不会被当成字段。

**列表**：字段后面一行一条，以 `- ` 开头：
```
步骤:
- 第一步
- 第二步
```

**分栏**：同一行里用 ` | ` 分几段（公式 `$…$` 里的 `|` 不算，绝对值照写 `$|x|$`）。

**行内标记**（只有这几种）：

| 写法 | 效果 |
|---|---|
| `$x^2+1$` | 行内公式（LaTeX）。分数写 `\tfrac{a}{b}`，根号 `\sqrt{x}`，乘号 `\times`，≤ ≥ 写 `\le \ge`，度数 `^\circ` |
| `$$…$$` | 独占一行的大公式（少用） |
| `**重点**` | 加粗 |
| `==答案==` | 答案胶囊（填空的答案） |
| `~~错误写法~~` | 划掉 |
| `〔k1:原文句子〕` | 原文里的句子，讲到键 k1 时变黄（用在「图: 原文」里） |
| `〔+k2:补充内容〕` | 讲到 k2 时才出现 |

**步骤**（例题、练习、讲题、精选的「步骤:」）：
```
步骤:
- 先写已知
- [ax] 对称轴 $x=-1$          ← 讲到这一步时，图里标了 [ax] 的东西亮起来
- [v dec] 顶点和递减段一起亮    ← 一步可以点亮多个
- ! 易错：开口向下时右侧下降    ← 「!」开头 = 易错步，红色
```
- 一页最多 **9 步**，每步一句话。步骤是**讲解的节奏**，不是把答案抄一遍。
- 写了 `[键]` 的步骤，图里**必须**有同名的 `[键]`，否则报错。
- 高亮**不累积**：每一步只亮这一步写的键，上一步亮的会灭。要一直亮着的，后面每一步都带上它的键：`[a]` → `[a b]` → `[a b c]`。

**字数红线**（超了会溢出页面，装配台会报错）：
- 页标题 ≤ 20 个字，一句话点破这一页（「对称轴右边是下坡」而不是「例题 2」）。
- 题干 ≤ 120 字；卡片、条目每条 ≤ 40 字；步骤每步 ≤ 40 字。

## 四、页型

先看场景能用哪些页型：

| 场景 | 可用页型 |
|---|---|
| 新授课 | 三卡 决策 例题 练习 推导 套路 对照 实验 图解 易错 总结 |
| 专题课 | 同新授课（复习课、微专题也按专题课写） |
| 讲评课 | 全景 速查 讲题 错因 对照 易错 |
| 微论坛 | 课标 考情 导图 核对 难点 图解 建议 精选 层级 推导 实验 对照 |
| 成绩分析 | **不写页**，只写整课设定（页全部由成绩表自动生成） |

### 三卡 —— 一个公式 / 概念 + 三个要点
```
@页 三卡 [从平移说起]
标题: 三个平移，一个口诀
引导: 把 $y=ax^2$ 的图象整体挪一挪，式子怎么变？
公式: $y=a(x-h)^2+k$
卡1: 左右平移 | $h>0$ 向右挪 $h$，$h<0$ 向左挪 $|h|$
卡2: 上下平移 | $k>0$ 向上挪 $k$
卡3: 形状不变 | $a$ 管开口，平移时不变
提醒: 左加右减**只管 x**，上加下减**只管整体**
```
正好 3 张卡，每张「名字 | 一两句」。

### 决策 —— 拿到题先问哪几句
```
@页 决策 [怎么判断]
标题: 拿到题先问三句
问答:
- 开口朝哪？ → 朝上：离轴越远越大 | 朝下反过来
- 轴在区间哪边？ → 左 / 中 / 右三种 | 画数轴比一比
收束: 三句问完，画一条数轴
```
每条「问题 → 答案 | 补充」，3–4 条。

### 例题 / 练习 —— 一道题，按步讲
```
@页 例题 [顶点式]
标题: 括号里变号，就是对称轴
题号: 例2
意图: 把「$(x+1)^2$」翻译成「对称轴 $x=-1$」 | 括号里变号，就是对称轴 | 把对称轴写成 $x=1$
提示: 读 a、h、k
题干: 说出抛物线 $y=-2(x+1)^2+3$ 的开口方向、对称轴和顶点。
图: 函数 x -4..3 y -4..4
- 曲线 y=-2(x+1)^2+3
- 竖线 x=-1 [ax]
- 点 A(-1,3) 坐标 [v]
图注: 对称轴右边是下坡
步骤:
- 看 $a=-2<0$，开口向下
- [ax] 对称轴 $x=-1$
- [v] 顶点 $(-1,3)$ 是最高点
- ==答案== 开口向下，对称轴 $x=-1$，顶点 $(-1,3)$
验算:
- 当 x=-1：-2(x+1)^2+3 = 3
```
- **必写** `意图: 卡点 | 破题 | 常错`（怎么想见《读题与画面》），**标题就是破题那句话**；「例题 1」「练一练」「巩固提升」这类标题会被退回。
- **答案里有数就必写** `验算:`，每行 `算式 = 结果`、`当 k=-12, x=-1：k/x = 12` 或 `-1/2 > -1`，装配台会真算，算不对就退回。选择题答案只是字母时可以不写。讲题、精选页同样适用。
- 可选字段：`标签`（题号旁小胶囊）、`侧栏: 小标题 | 一句提醒`、`出处`（真题写「2024·广州·中考」，学校期中期末卷照实写，不许写成真题）、`原题: 3`（这页用的是原稿第几题，可写 `2-3`）、`做笔记: 是`、`宽图: 是`（图放宽）、`变式: 上一题 | 改了什么 | 变成`（放在题目上方的变式条，续课开场用）、`页底: 标题` + 列表（页底的小套路条）。
- **例题、练习**都写 `计时: 2:30`；练习可以没有步骤（纯练）。
- 新授课、专题课：**所有例题和练习的计时加起来正好 20:00**（1200 秒），其余页不计时。

### 推导 —— 式子一步步变形的动画
```
@页 推导 [顶点式]
标题: 一般式配成顶点式
题号: 例1
题干: 把 $y=x^2-4x+3$ 化成顶点式。
推导标题: 配方
依据: 完全平方公式
推导:
- y=x^2-4x+3 | 原式
- y=x^2-4x{{+4-4}}+3 | 加 4 再减 4
- y=(x-2)^2-1 | 凑成完全平方
结论: 顶点 $(2,-1)$，对称轴 $x=2$
技巧:
- 一次项系数一半 | $-4$ 的一半是 $-2$
```
- 「推导:」每行 `式子 | 这一步做了什么`，式子**不加 $**，2–6 行。`{{…}}` 包住的部分黄色高亮（新加进来的东西）。
- 只在「变形过程本身就是考点」时用（配方、移项、化简）。普通计算写成例题步骤即可。

### 套路 —— 三步方法 + 反套路 + 一张图
```
@页 套路 [怎么判断]
标题: 三步套路：画轴、比位置、取端点
三步:
- ① 求对称轴
- ② 看轴在区间左、中、右
- ③ 单调段取端点，含轴取顶点
观察: 开口向上时，最小值看轴
反套路:
- 不画图直接代端点
图: 函数 x -1..5 y -2..6
- 曲线 y=(x-2)^2-1
- 带 0..3
图注: 区间包含对称轴
```

### 对照 —— 表格对比，逐行出现
```
@页 对照 [小结]
标题: 两类题放一起比
表:
- 类型 | 谁在动 | 常见错
- 轴定区间动 | 区间 | 漏掉轴在区间内
- [重点] 口诀 | 动的去碰不动的 | 画图再分类
记住: 先画图，再分类
```
第一行是表头；`[重点]` 开头的行加底色。`逐行: 否` 表示一次全显示。

### 实验 —— 学生拖滑条，图和读数跟着变
```
@页 实验 [从平移说起]
标题: 拖一拖：h、k 怎么推着抛物线走
先猜: $h$ 从 0 拖到 2，抛物线往哪边走？
拖:
- h 左右 -3..3 步 0.5 初值 0
- k 上下 -3..3 步 0.5 初值 0
图: 函数 x -5..5 y -4..6
- 曲线 y=(x-h)^2+k
- 曲线 y=x^2 虚线
- 点 P(h,k)
读数: 顶点 $({h},{k})$，对称轴 $x={h}$
图注: 虚线是 $y=x^2$
```
- 「拖:」每行 `变量 名字 最小..最大 步 0.1 初值 2 单位 m`，变量是一个英文字母。
- 图里的式子、点坐标可以直接用变量。
- 「读数:」里 `{式子}` 显示算出来的数，`{条件 ? 甲 : 乙}` 按条件选一句，如 `{h>0 ? 向右 : 向左}`。

### 图解 —— 1–3 张小图，各配一句话
```
@页 图解 [难点突破]
标题: 两个关键图，一眼看懂
卡1: 关键一：串联看电流
图1: 柱状 单位 W
- 灯 L1 6
- 灯 L2 3
说明1: 串联电流相同，电阻大的功率大
卡2: 关键二：并联看电压
图2: ……
说明2: ……
口诀: 串联比电阻，大的更亮
```

标题: 八个最容易丢分的地方
条目:
- 左加右减记反 | $y=(x+2)^2$ 是向**左**平移

### 总结 —— 知识骨架导图（学生先填再揭晓）
```
@页 总结 [易错与总结]
标题: 这节课的骨架
根: $y=a(x-h)^2+k$
枝1: 平移
- 左加右减管 x
- 上加下减管整体
枝2: 性质
- 顶点 $(h,k)$

- 配方化顶点式
```
2–4 枝，每枝 2–5 片叶子，叶子 ≤ 12 字。

### 讲评课专用

**全景**（自动：各班均分 + 各题得分率）：只写 `标题:`。

**速查**（选择题一页 1–4 道，按 ▶ 逐题揭答案）：
```
@页 速查 [选择题]
标题: 选择题 9、10：三分钟对完
题1: 9
题干1: 反比例函数 $y=\tfrac{k}{x}$ 的图象在二、四象限，则
选项1: A. $k>0$；B. $k<0$；C. $k\ge 0$；D. $k\le 0$
思路1: 二、四象限 → $k<0$
关键1: 象限看 $k$ 的符号
易错1: 选 D 的 {9.D} 人：$k=0$ 不是反比例函数
题2: 10
……
```
`题N:` 写**成绩表里的题号**，一字不差。

**讲题**（一道主观题，得分率和「本题错的人」名单自动出现）：
```
@页 讲题 [解答压轴]
标题: 第 19(2) 题：面积最值，先写函数再配方
小问: 19(2)
题干: ……
图: ……
步骤:
- ……
```
`小问:` 写成绩表表头里的题号，多个用 ` | ` 隔开，如 `小问: 13(1) | 13(2)`。

**错因**（最多 4 条，每条五段）：
```
@页 错因 [错因]
标题: 丢分最多的三类错
条目:
- 配方漏系数 | {19(2).错} 人没拿满 | $-2(x-5)^2+25$ | 常数项也要乘 $-2$ | $-2(x-5)^2+50$
记住: 写完答案，代一个值回去验一验
```
五段：标题 | 人数 | 学生写的 | 错在哪 | 应该写。

**数字占位符**（讲评课里所有人数、得分率都用它，**不许自己编数字**）：

| 写法 | 意思 |
|---|---|
| `{19(2).错}` | 这题没拿满的人数 |
| `{19(2).对}` | 拿满的人数 |
| `{19(2).率}` | 得分率（带 %） |
| `{9.B}` | 选择题选 B 的人数（`{9.空}` = 没选的） |
| `{人数}` | 参考总人数 |

在「讲题」页里可以省掉题号：`{错}` `{率}` 指本页第一个小问。

### 微论坛专用

**课标**：有截图写 `图1: 文件名.png | 说明`；没有截图写 `摘录:` 列表（**只能抄老师给的原文**）。`脚注:` 写出处。

**考情**：
```
表:
- 年份 | 题号 | 题型 | 分值 | 考点
- 2024 | 21 | 解答 | 8 | 二次函数综合
脚注: 数据来源：老师提供的 2022–2024 中考细目表
```
脚注**必须**写「来源」；没核实的格子写 `待核`。

**导图**：同「总结」（根 + 枝N + 叶子），但直接显示，按 ▶ 逐枝展开。

**核对**（教材 / 练习册的问题清单，≤ 12 行）：
```
说明: 下面是备课时发现的问题
条目:
- 第 13 课时 | 第 2 题 | 口径 | 答案漏了一种情况 | 补上 $x=-1$
```
五段：课时 | 题号 | 类别 | 问题 | 建议。类别只能是 **事实 / 口径 / 提醒 / 存疑**。

**难点**：`条目:` 每行 `核心知识点 | 难点1；难点2`。

**建议**：`建议:` 正好 5 条（情境导入 → 课件互动 → 支架 → 追问对比 → 评价与素养），`文献:` 每条 `[n] 作者.(年). 篇名. 刊名, (期), 页. | 用在哪`，全课编号连续。

**层级**：`条目:` 每行 `层次 | 知识要求 | 外在体现`；`== 小标题` 开头的行是分组标题。

**精选**：同例题，多 `出处:`（必填）和 `层次:`（必须是层级表里有的层次）。

## 五、图（「图:」字段）

第一行写**图的种类和范围**，下面每行画一样东西。
每样东西后面可以加 `[键]`：常显示，讲到这个键时亮黄光；`[+键]`：讲到这个键时才出现。
颜色词：红 蓝 绿 黄 紫 青；另有「虚线」「空心」。

| 种类 | 第一行 | 每行可写 |
|---|---|---|
| 函数 | `图: 函数 x -4..3 y -4..4`（可加 `格 5`、`不等比`、`横轴 V/cm³`、`纵轴 F/N`） | `曲线 y=…`（可加 `从 0 到 10`、`不标`）；`点 A(1,-4)`（加 `坐标` 显示坐标）；`竖线 x=1 对称轴`；`横线 y=0`；`线段 (0,0)-(2,4)` 或 `线段 A-B`（端点可用已画的点名，加 `虚线` 画垂线段）；`多边形 O-A-P-B 标 S=6`（面积阴影，淡黄填充，顶点用点名或坐标，O 默认原点，`标` 后的文字写在图形中间）；`带 1..3`（竖条阴影）；`标注 (2,3) 文字` |

> 题目里的点是字母坐标（如 $A(x_1,y_1)$、$P(m,n)$）时，图里**挑一个符合题意的具体点**来示意，例如 `点 A(-2,-0.5)`，不加 `坐标`（只显示点名 A）。点坐标只能写数字。

- 原图的图片要老师在装配台上传，文件名一字不差。**没有图片就别写原图**，用函数、表格等自己画。
- 图注（`图注:`）一句话点破这张图要看什么；图下面没有图注会有提醒。
- 函数式子写法：**一律写成 `y=…`，自变量一律用 `x`**：`y=x^2-2x-3`、`y=\frac{k}{x}`、`y=\sqrt{x}`、`y=sin(x)`，乘号可省（`2x`、`kx`）。物理量（$V$、$F$、$t$）不要写进式子，用 `横轴` `纵轴` 标名称：`图: 函数 x 0..100 y 0..1.2 横轴 V/cm³ 纵轴 F/N`，曲线写 `y=0.01x`。
- **没有老师上传的图片，就不要写「原图」**（写了会报「找不到图片」）；用函数、表格、流程等自己画。
- 键用字母、数字或短中文都行（`[a1]`、`[顶点]`），但步骤里的键必须和图里的一字不差。
- 表格**一个格子只放一个键**：`45 [b]` 可以，`45 [a] [b]` 会把后一个键当文字显示出来；要两处都亮，就拆成两列。
- 多条曲线会自动轮换颜色；两车、两组这类要「同色同组」的，在行尾写颜色词强制：`曲线 y=4x-380 绿`。
- `[+键]` 的东西只在亮这个键的那一步出现，下一步就隐藏；想让它留到最后，在最后一步也写上这个键。
- 实际问题的自变量是 $t$、$l$、$R$ 时，曲线照样写 `y=6300/x 不标`，真正的式子（如 $v=\tfrac{6300}{t}$）写进 `图注:`。
- 不想标字母的点写 `点 (110,2)`；点名可带下标：`点 D₁(0,-5)`。
- 新授课、专题课要写 `原稿题号:`，原稿每道题都要被某页的 `原题: N`（可写 `原题: 8-9`）用到，或写进 `删题:` 说明为什么删。

## 六、成绩分析

只写整课设定，**不写任何页**：
```
@课件
场景: 成绩分析
考试: 九年级 9 月月考
学科: 数学
年级: 九年级
署名: 数学科组
// 以下可选
满分: 120
阈值: 优秀 85 良好 75 及格 60 低分 40
冲: 30
保: 40
```
- 阈值是**满分的百分比**（默认 优秀 80 良好 70 及格 60 低分 40）。
- 冲 / 保 = 临界生范围：线后多少名内算「冲」，线前多少名内算「保」（默认 30 / 40）。
- 均分、四率、梯度线、达线、临界生、热力图、进退步、各班处方全部由成绩表算出来；有梯度线表才出达线页，有历次名次表才出走势页。

## 七、装配台报错怎么改

装配台检查完会给你一份「修改意见」，每条带行号和改法。**照着改，然后输出完整的课件稿**（从 `@课件` 开始），不要只输出改动的部分，不要解释。
