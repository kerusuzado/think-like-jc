# 历史（初中统编版 七上–九下；高中统编版 中外历史纲要上下 + 选择性必修 1–3）

## 用什么图
- 时间线**首选** `图: 年代轴`：`事件 1840 鸦片战争`、`时段 1919..1949 新民主主义革命`；公元前写负数，没有公元 0 年。
- 因果、过程 → `图: 流程`（背景 → 经过 → 结果 → 影响）。
- 史料题 → `图: 原文`（材料原文，关键信息 `〔k:…〕` 点亮）；图片史料用老师给的原图。
- 数据变化（人口、产量）→ `折线` / `柱状`，图注写来源。

## 怎么讲
- 史料题三步：**读出处（时间、作者、类型）→ 抓关键词 → 结合所学说明**。
- 比较题 → 「对照」页（背景 | 内容 | 性质 | 影响）。
- 时空观念：每节课至少一页年代轴。
- 课本页码、人物言论拿不准时标「待科组审」，不编造史料。

## 初中 / 高中
- 初中：按时间讲故事，重点事件和人物；识记为主。
- 高中：通史 + 专题，史料实证、历史解释；材料题要分析「为什么这么说」。

## 易错举例
- 「《南京条约》割香港岛，不是九龙」；「辛亥革命推翻的是清朝统治和两千多年的君主专制制度」；「年代轴上公元前 221 年在公元前 206 年的**左边**」。
