# 语文（初中、高中都用统编版教材，人民教育出版社出版；高中 必修上下册 + 选择性必修上中下册）

## 用什么图
- 语文的「图」主要是**原文**：`图: 原文 《岳阳楼记》节选`，一行一段；要讲的句子写 `〔k1:句子〕`，步骤 `[k1]` 时变黄；答案、赏析写 `〔+k2:……〕` 讲到才出现。
- 文章结构、情节发展 → `图: 流程`（开端 → 发展 → 高潮 → 结局）；情感变化 → `图: 折线`（段落 1–6 的情感强度，图注写「示意，不按比例」）。
- 字词、修辞、句式对比 → 「对照」页。

## 怎么讲
- 阅读题：**找句（点亮原文）→ 抓关键词 → 按答题模式组织 → 示范答案**。给分点分块写：「分三块：手法 1 分 + 内容 1 分 + 情感 1 分」。
- 文言文：先圈得分字（词类活用、通假、特殊句式）→ 每个字的意思 → 连成整句；特殊句式单独一页「对照」。
- 作文：审题（关键词）→ 立意（三个层次对照）→ 结构（流程）→ 升格（原句 → 改句，用「对照」）。
- 讲评课：默写题老师看原卷判，写「本页只对答案」，不写人数。

## 初中 / 高中
- 初中：记叙文、说明文、议论文三分；古诗文以背诵理解为主。
- 高中：任务群、群文阅读、思辨读写；文言文断句、翻译要求更严；论述类文本分析论证结构（用流程图）。

## 易错举例
- 「『乐之』是意动用法：以之为乐」；「答题只写手法不写效果，只得 1 分」；「病句『通过……使……』缺主语」。
