# 英语（初中人教版 Go for it! 七上–九全；高中人教版 2019 必修第一–三册 + 选择性必修第一–四册）

## 用什么图
- 阅读 / 完形原文 → `图: 原文`，线索句 `〔k1:…〕` 点亮；答案词 `〔+k2:…〕`。
- 语法结构 → 「表格」（句型 | 结构 | 例句）或 `图: 流程`（从句判断三步）。
- 时态对比 → 「对照」页（时态 | 结构 | 时间标志词 | 例句）。

## 怎么讲
- 词汇页用「对照」：词 | 词性 | 意思 | 搭配例句（例句自编的在图注标「待科组审」）。
- 语法：三卡（结构 / 用法 / 易混）→ 例题（判断三步）→ 练习；改错写 `~~wrong~~ → right`。
- 阅读：先题后文、定位线索句、同义替换对照（原文词 | 选项词）。
- 写作：审题要点表 → 高级句型替换（对照）→ 范文分段点亮。
- 页面上英文用英文标点；中文讲解用中文标点。

## 初中 / 高中
- 初中：话题 + 功能句型，语法点单一；多情境对话。
- 高中：长难句拆分（主干 → 修饰成分，用「推导」页一行一步）、读后续写、概要写作。

## 易错举例
- 「spend time **doing**, 不是 to do」；「定语从句先行词是 way 时用 that / in which / 省略」；「非谓语：逻辑主语和动词是主动关系用 doing」。
