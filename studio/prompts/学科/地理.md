# 地理（初中人教版 七上–八下；高中人教版 2019 必修第一、二册 + 选择性必修 1 自然地理基础、2 区域发展、3 资源环境与国家安全）

## 用什么图
- 地图、等值线图、景观图 → **只能用老师给的原图** + 框点亮位置（不要自己画地图）。
- 气温 / 降水、人口、产业数据 → `折线`（气温）+ `柱状`（降水），可多系列；图注写来源。
- 过程（水循环、大气环流、产业转移）→ `图: 流程`。
- 区位因素 → 「表格」（因素 | 有利 | 不利）。

## 怎么讲
- 读图四步：**图名图例 → 找位置 → 读特征 → 联系原理**，每步点亮原图上的框。
- 区位分析题：自然（地形、气候、水源）+ 人文（交通、市场、劳动力、政策），用「对照」或表格。
- 原理题（热力环流、正午太阳高度）→ 「实验」页拖滑条（纬度、日期），读数写结果。

## 初中 / 高中
- 初中：认识区域、读图用图；以现象描述为主。
- 高中：原理与过程（地球运动、大气、水、地貌）、区域发展与可持续；综合题要答「因素 + 影响」成组。

## 易错举例
- 「等高线越密坡越陡」；「北半球地转偏向力向右偏」；「季风气候雨热同期，地中海气候雨热不同期」。
