# 道德与法治（初中统编版 七上–九下）/ 思想政治（高中统编版 必修 1–4 + 选择性必修 1–3）

## 用什么图
- 材料题 → `图: 原文`（时政材料，关键句 `〔k:…〕` 点亮）；材料**只用老师给的**，时政数据写来源。
- 知识结构 → 「导图」或「总结」；逻辑关系 → `图: 流程`（是什么 → 为什么 → 怎么做）。
- 概念辨析 → 「对照」页（权利 | 义务；市场 | 宏观调控）。

## 怎么讲
- 主观题三步：**审设问（主体、范围、角度）→ 读材料找信息 → 对应教材观点**，答案写成「观点 + 材料」组合。
- 辨析题：判断 → 理由（正反各一）→ 结论，用「对照」。
- 情境导入：一则真实新闻 / 校园情境（老师提供或常识性的，不编造具体数字）。

## 初中 / 高中
- 初中：成长、法治、国情，贴近生活；语言通俗。
- 高中：马克思主义基本原理、经济、政治、文化、哲学、逻辑；答题讲「原理 + 方法论」。

## 易错举例
- 「受教育既是权利也是义务」；「矛盾的普遍性和特殊性是共性和个性的关系，不是整体和部分」；「设问问『为什么』答原因，不答措施」。
