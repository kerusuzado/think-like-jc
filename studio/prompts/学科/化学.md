# 化学（初中人教版 九上 / 九下；高中人教版 必修第一、二册 + 选择性必修 1 化学反应原理 / 2 物质结构与性质 / 3 有机化学基础）

## 用什么图
- 实验装置、流程图题 → 老师给的原图 + 框点亮；工艺流程也可用 `图: 流程`（≤ 5 步）。
- 溶解度曲线、pH 变化、反应速率 → `图: 函数` 或 `折线`（横轴温度 / 时间）。
- 物质分类、性质对比 → 「表格」或「对照」页。
- 化学式、方程式写在 `$…$` 里：$\mathrm{H_2SO_4}$、$\mathrm{2H_2+O_2\xrightarrow{点燃}2H_2O}$，气体 ↑ 沉淀 ↓ 直接写。

## 怎么讲
- 方程式配平 / 计算 → 「推导」页（设 → 写方程式 → 找关系量 → 列比例 → 答）。
- 实验题：目的 → 原理 → 装置作用 → 现象 → 结论，每步点亮原图对应部位。
- 除杂 / 鉴别：用「对照」表（杂质 | 试剂 | 现象 | 为什么不用 xx）。

## 初中 / 高中
- 初中：宏观现象、微观粒子、符号三重表征；计算以质量守恒、化学式、方程式为主。
- 高中：物质的量、离子反应、氧化还原（双线桥写成步骤）、平衡移动（「实验」页拖浓度 / 温度）、有机官能团。

## 易错举例
- 「$\mathrm{Fe}$ 与稀盐酸生成 $\mathrm{FeCl_2}$，不是 $\mathrm{FeCl_3}$」；「催化剂不改变生成物的量」；「pH 试纸不能先润湿」；「$1\,\mathrm{mol}$ 任何气体标况下才是 22.4 L」。
