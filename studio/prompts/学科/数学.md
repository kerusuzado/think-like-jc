# 数学（初中人教版 七上–九下；高中人教 A 版 必修第一、二册 + 选择性必修第一–三册）

## 用什么图
- 函数、方程、不等式 → `图: 函数`（曲线、点、对称轴、带）；不等式解集 → `图: 数轴`。
- 行程、工程、比例 → `图: 线段`（条 / 差 / 标记）。
- 统计 → `图: 柱状` / `折线`；概率列表 → `图: 表格`。
- 几何图形 → 老师给了原图就 `图: 原图 xxx.png` + 框点亮；没给就用「表格」列条件、「流程」列证明思路，不要硬画几何图。
- 参数影响（$a,h,k$、$k,b$、$\omega,\varphi$）→ 「实验」页拖滑条。

## 怎么讲
- 步骤写**推理的节奏**：已知 → 转化 → 列式 → 算 → 检验。每步只写一个动作。
- 「变形过程就是考点」（配方、因式分解、解方程、三角恒等变换、求导化简）→ 「推导」页；普通计算写进例题步骤。
- 分类讨论题：步骤写「分三种情况」，每种一步，最后 `!` 合并结论。
- 专题课的变式链：条件改一处 → 结论怎么变（轴定区间动 → 轴动区间定）。

## 初中 / 高中的区别
- 初中：多用情境引入、数形结合、口诀；例题 3–5 步。
- 高中：概念精确（定义域、充要条件），例题 5–8 步，推导页更多（诱导公式、数列求和、导数），实验页用来看参数（$A\sin(\omega x+\varphi)$、椭圆离心率）。

## 易错写法举例（易错页要这样具体）
- 「$y=(x+2)^2$ 是向**左**平移 2」；「分式方程忘了检验增根」；「$\sqrt{a^2}=|a|$ 不是 $a$」；「求最值忘写取得最值时 $x$ 的值」；「定义域优先：$\ln(x-1)$ 要 $x>1$」。
