# 物理（初中人教版 八上–九年级全一册；高中人教版 必修第一–三册 + 选择性必修第一–三册）

## 用什么图
- 运动：`图: 函数` 画 $s$-$t$ / $v$-$t$ 图（x 轴是时间），`图: 线段` 画相遇追及。
- 力：没有受力图原图时用「表格」列出每个力（名称 | 施力物体 | 方向 | 大小）；有原图用原图 + 框。
- 电路：用老师给的电路图原图；数据比较用 `柱状`；变化规律（$P$ 随 $U$）用「实验」拖滑条。
- 实验题：`图: 流程`（步骤 ≤ 5）+ 「表格」（数据记录）。

## 怎么讲
- 计算题四步：**写已知（统一单位）→ 选公式 → 代入 → 答**。单位换算那一步放进「推导」并用 `{{…}}` 黄底。
- 概念辨析（额定 / 实际、质量 / 重力、功 / 功率）→ 「对照」页。
- 物理量变化的判断 → 「实验」页：先猜再拖，读数模板写 `{条件 ? 变大 : 变小}`。

## 初中 / 高中
- 初中：现象 → 规律，定性为主，公式少；每道计算题都写单位。
- 高中：矢量方向、图象斜率 / 面积的意义、临界条件；推导页多（牛顿第二定律应用、动能定理、动量守恒）。

## 易错举例
- 「速度单位 km/h 换 m/s 要除以 3.6」；「串联电流相同，电阻大的功率大；并联相反」；「摩擦力方向与**相对运动**方向相反，不是与运动方向相反」；「$v$-$t$ 图面积是位移，不是路程」。
