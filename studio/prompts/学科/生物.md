# 生物（初中人教版 七上–八下；高中人教版 必修 1 分子与细胞、必修 2 遗传与进化 + 选择性必修 1 稳态与调节、2 生物与环境、3 生物技术与工程）

## 用什么图
- 结构图（细胞、器官、生态系统）→ 老师给的原图 + 框点亮；没图就用「表格」（结构 | 功能）。
- 过程（光合作用、呼吸、反射、遗传中心法则、实验步骤）→ `图: 流程`。
- 数据（种群数量、光合速率随光照）→ `图: 折线` / `函数`（曲线点亮拐点）。
- 遗传图解 → 「推导」页一行一代（P → F₁ → F₂），或「表格」画棋盘。

## 怎么讲
- 概念先对照再应用：有丝 / 减数分裂、光合 / 呼吸、体液 / 细胞免疫 → 「对照」页。
- 实验题：变量（自变量 | 因变量 | 无关变量）用表格；对照组设计写成步骤。
- 遗传计算：先写基因型 → 再写配子 → 再算概率，每步一句，`!` 标「自交 / 自由交配」区别。

## 初中 / 高中
- 初中：认识结构与功能、生活联系（健康、环境）；多图少算。
- 高中：分子机制、遗传规律计算、稳态调节模型；图表分析题多，讲解要落到「曲线某段为什么上升」。

## 易错举例
- 「光合作用产生的 $\mathrm{O_2}$ 来自水，不来自 $\mathrm{CO_2}$」；「病毒没有细胞结构」；「$Aa$ 自交后代显性中纯合子占 $\tfrac13$，不是 $\tfrac14$」。
